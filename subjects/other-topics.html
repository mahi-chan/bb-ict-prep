    1. Web technology

    The web stack rests on three layers:

    LayerLanguageRole
    StructureHTMLSemantic content and document structure
    PresentationCSSVisual styling, layout, responsive design
    BehaviourJavaScriptInteractivity, DOM manipulation, async calls

    HTML5 semantic elements: <header>, <nav>, <main>, <article>, <section>, <aside>, <footer>.

    CSS layout models: Flexbox (1D — row or column), CSS Grid (2D — rows and columns). Media queries enable responsive design: @media (max-width: 768px) { }.

    JavaScript key concepts: event-driven, single-threaded with event loop, async via callbacks/promises/async-await, DOM API, fetch API for HTTP requests.

    Client-side vs server-side rendering:

    CSR (SPA)SSR
    Browser renders using JS (React, Vue)Server generates full HTML
    Faster navigation after initial loadFaster first paint, better SEO
    Heavier initial downloadMore server load per request
    HTML5 semantic page structure

  <article>
    <section>
      <h2>Section heading</h2>

</main>

    The exam typically asks "compare HTML, CSS and JavaScript" or "what is responsive web design" — keep answers structured around the three-layer model.

    HTTP status codes:

    REST is dominant in modern systems, but many banks still use SOAP for core integrations because of its built-in security features (WS-Security) and strict contracts (WSDL).

    3. Data centre

    A data centre houses servers, storage and networking equipment. Key considerations:

    ComponentPurposeKey metric
    UPSBattery backup during power failureRuntime in minutes
    GeneratorExtended backup beyond UPSFuel capacity / hours
    HVAC/CRACCooling — maintain 18–27°CPUE (Power Usage Effectiveness)
    Fire suppressionGas-based (FM-200, Novec) — no waterDetection time
    Physical securityBiometrics, mantraps, CCTVAccess control layers
    Raised floorCable management, under-floor coolingFloor height
    PUE = Total facility power / IT equipment power
    Ideal PUE = 1.0; average ≈ 1.58; Google achieves ≈ 1.10

    Tier classification (Uptime Institute):

    TierUptimeRedundancyDowntime/year
    I99.671%None28.8 hrs
    II99.741%Partial (N+1)22 hrs
    III99.982%Concurrently maintainable1.6 hrs
    IV99.995%Fault tolerant (2N)26 min

    Disaster Recovery (DR): RPO (Recovery Point Objective — max acceptable data loss) and RTO (Recovery Time Objective — max acceptable downtime). Hot site (immediate), warm site (hours), cold site (days).

    Bangladesh Bank requires Tier III or above for core banking data centres with a geographically separate DR site. The PUE and tier classifications are frequently asked in exams.

    4. Digital logic

    Digital logic uses binary (0/1) signals processed through logic gates. The seven fundamental gates:

    GateSymbolExpressionOutput = 1 when
    ANDA·BY = A AND BBoth inputs = 1
    ORA+BY = A OR BAt least one input = 1
    NOTA′Y = NOT AInput = 0
    NAND(A·B)′Y = NOT(A AND B)Not both 1 (universal gate)
    NOR(A+B)′Y = NOT(A OR B)Both inputs = 0 (universal gate)
    XORA⊕BY = A XOR BInputs differ
    XNOR(A⊕B)′Y = A XNOR BInputs same

    Universal gates: NAND and NOR can each implement any logic function alone. Any AND, OR, NOT can be built from NAND gates only (or NOR gates only).

    Combinational circuits: half adder (XOR + AND), full adder, multiplexer, decoder, encoder. Sequential circuits: flip-flops, registers, counters — these have memory and are covered in more detail under Telecommunication.

    NAND is called "universal" because you can build any digital circuit using only NAND gates. This is why NAND flash memory is named after the gate — the cells use NAND gate structures.

    S4 Why are NAND and NOR called universal gates? Show how to implement AND using NAND gates only. standard repeat

    A gate is universal if any Boolean function can be implemented using only that gate. NAND and NOR each satisfy this because each can implement NOT, AND and OR:

    AND using NAND gates:

    Step 1: NAND(A, B) = (AB)′
    Step 2: NOT the result: NAND((AB)′, (AB)′) = ((AB)′)′ = AB
    AND = two NAND gates (one NAND followed by NAND-as-NOT)

    OR using NAND: NAND(NAND(A,A), NAND(B,B)) = NAND(A′, B′) = (A′B′)′ = A+B (De Morgan).

    S5 What is Digital Bangladesh? List the four pillars of Smart Bangladesh (Vision 2041). standard repeat

    Smart Bangladesh (Vision 2041) extends this with four pillars:

    3. Smart Government: paperless governance, AI-driven decision making, interoperable systems (BNDA)
    4. Smart Society: universal digital access, smart cities, digital healthcare and education

    S8 What is PUE? A data centre uses 500 kW total and 350 kW for IT. Calculate PUE and comment. standard repeat
    PUE = Total power / IT power = 500/350 = 1.43

    A PUE of 1.43 means for every 1 kW used by IT, 0.43 kW is used for cooling, lighting, etc. This is good (below the industry average of ~1.58) but not exceptional (Google achieves ~1.10).

    Improvement strategies: hot/cold aisle containment, free cooling (using outside air), raising server inlet temperature, virtualization to reduce total servers.

    S9 Explain the Bangladesh ICT Act 2006. What are its key provisions? standard repeat

    The ICT Act 2006 (amended 2009, 2013) is Bangladesh's primary legislation for electronic transactions and cyber offences.

    Key provisions:

    • Legal recognition of electronic records and digital signatures
    • Establishment of a Certification Authority (CA) for digital signatures
    • E-governance — government can conduct official business electronically
    • Cyber crime definitions: hacking, identity theft, phishing, cyber terrorism
    • Penalties for publishing offensive/defamatory content online
    • Controller of Certifying Authorities (CCA) as regulatory body

    Note: The Digital Security Act 2018 later superseded many of the cyber crime provisions with updated definitions and a dedicated Digital Security Agency.

    S10 Design a half adder and a full adder using logic gates. Show truth tables. standard repeat

    Half adder — adds two 1-bit numbers:

    ABSumCarry
    0000
    0110
    1010
    1101
    Sum = A ⊕ B (XOR), Carry = A · B (AND)

    Full adder — adds two bits plus a carry-in:

    Sum = A ⊕ B ⊕ Cin
    Cout = AB + Cin(A ⊕ B)
    A full adder = two half adders + one OR gate

    Practice questions

    10 questions
    P1 Explain responsive web design. What are media queries and how are they used? practice

    Responsive design makes a website adapt to different screen sizes (desktop, tablet, phone) using fluid layouts, flexible images and CSS media queries.

    Media query: a CSS rule that applies styles conditionally:

    @media (max-width: 768px) {
  .sidebar { display: none; }
  .main { width: 100%; }
}

    Techniques: viewport meta tag, percentage widths, Flexbox/Grid, min/max-width, rem/em units, mobile-first approach (start with small screen, add complexity for larger).

    P2 Explain RPO and RTO in disaster recovery. A bank has RPO=1hr and RTO=4hrs — what does this mean? practice

    RPO = 1 hour: the bank can tolerate losing at most 1 hour of data. Backups/replication must happen at least every hour.

    RTO = 4 hours: the bank must restore services within 4 hours of a disaster. The DR site must be able to take over within that window.

    Implications: requires at least a warm DR site (hot site for RTO < 1hr), synchronous or near-synchronous data replication, tested failover procedures, and automated monitoring to detect failures quickly.

    P3 Implement OR and NOT using only NOR gates. practice

    NOT using NOR:

    NOR(A, A) = (A+A)′ = A′ → NOT = NOR with both inputs tied

    OR using NOR:

    Step 1: NOR(A, B) = (A+B)′
    Step 2: NOT the result: NOR((A+B)′, (A+B)′) = ((A+B)′)′ = A+B
    OR = two NOR gates (NOR followed by NOR-as-NOT)
    P4 What is the difference between 401 Unauthorized and 403 Forbidden HTTP status codes? practice
    CodeMeaningAction
    401 UnauthorizedNot authenticated — identity unknownRe-authenticate (login, provide API key)
    403 ForbiddenAuthenticated but not authorised — identity known, permission deniedRequest elevated privileges or different credentials

    Example: A teller logs in (passes 401 check) but tries to access the admin dashboard (gets 403 because their role doesn't have permission).

    P5 What is BNDA (Bangladesh National Digital Architecture)? Why is it important? practice

    BNDA is a government-mandated interoperability framework ensuring that all government digital systems can exchange data seamlessly.

    Key components:

    • National Enterprise Architecture: standardised technology choices
    • Interoperability framework: APIs, data formats and protocols for system integration
    • Shared digital platforms: common services (identity, payment, notification) that all systems can use
    • Data standards: uniform data definitions across government

    Importance: prevents siloed systems, reduces duplication, enables citizen-centric "once-only" data provision, and supports the Smart Bangladesh vision.

    P7 What are cookies and sessions? How do they maintain state in HTTP? practice

    HTTP is stateless — each request is independent. Cookies and sessions add state:

    FeatureCookieSession
    StorageClient (browser)Server (memory/DB)
    Size limit~4 KB per cookieServer memory (larger)
    SecurityVisible to client; can be stolen (XSS)Only session ID sent to client
    LifetimeSet by Expires/Max-AgeUntil timeout or logout
    Use caseRemember preferences, trackingAuthentication state, cart

    How they work together: server creates a session and sends a session ID as a cookie. Each subsequent request includes the cookie, letting the server identify the user.

    P8 What is the Digital Security Act 2018 of Bangladesh? List its key provisions. practice

    The Digital Security Act (DSA) 2018 replaced parts of the ICT Act 2006 and established a comprehensive legal framework for cyber security in Bangladesh.

    Key provisions:

    • Establishment of the Digital Security Agency under the ICT Division
    • Creation of a national Computer Emergency Response Team (CERT)
    • Critical Information Infrastructure (CII) designation and protection
    • Offences: hacking, identity theft, cyber terrorism, defamation, spreading religious hatred online
    • Digital forensics lab and investigation procedures
    • Penalties ranging from fines to imprisonment (up to 14 years for terrorism-related offences)
    P9 Design a 4-to-1 multiplexer using logic gates. Show the truth table and Boolean expression. practice

    A 4-to-1 MUX has 4 data inputs (I₀–I₃), 2 select lines (S₁, S₀) and 1 output Y.

    Y = S₁′S₀′I₀ + S₁′S₀I₁ + S₁S₀′I₂ + S₁S₀I₃
    S₁S₀Output Y
    00I₀
    01I₁
    10I₂
    11I₃

    Implementation: 4 AND gates (one per data input, each gated by the appropriate select combination), fed into a 4-input OR gate. Plus 2 NOT gates for the inverted select lines.

    P10 What is server virtualisation? Explain hypervisor types and their advantages. practice

    Server virtualisation runs multiple virtual machines (VMs) on a single physical server, each with its own OS and applications.

    TypeAlso calledRuns onExamples
    Type 1 (bare-metal)NativeDirectly on hardwareVMware ESXi, Hyper-V, KVM
    Type 2 (hosted)HostedOn top of host OSVirtualBox, VMware Workstation

    Advantages: server consolidation (higher utilisation, fewer physical servers), isolation between workloads, easier DR (snapshot/migrate VMs), rapid provisioning, reduced power and cooling costs.
