    1. Computer generations

    A "generation" is defined by its switching element — the component that represents a 0 or a 1 inside the machine. Each generation made this element smaller, faster and cheaper, which is the only reason computing moved from one room-sized calculator to the phone in your pocket.

    Gen Period Switch Speed Language Example
    1st 1940–56 Vacuum tube ms Machine code ENIAC, UNIVAC I
    2nd 1956–63 Transistor µs Assembly, FORTRAN, COBOL IBM 7094
    3rd 1964–71 Integrated circuit (IC) ns C, BASIC IBM 360
    4th 1971–present Microprocessor (VLSI) ps C++, Java, Python Intel 4004, modern PCs
    5th present–future AI / parallel — Prolog, natural language Watson, quantum prototypes
    PatternEach generation reduced size by ~10×, speed by ~100×, and cost by ~10×.
    Moore's lawTransistor count on a chip doubles roughly every 2 years — that is the engine behind generations 3 → 4 → 5.
    Why the generation question keeps appearing. The examiner wants you to link technology → speed unit → language level → example machine. Fill in the table row by row and you have the full answer.

    2. Classification

    Computers are classified along two independent axes — by signal type and by size / purpose. The first axis is a design choice (analog vs digital); the second is a market segmentation that matters for exam questions about "which type of computer is used for X."

    Embedded systems (ATMs, routers, washing machines) and workstations (CAD, animation) sit between micro and mini. Servers range from micro to mainframe depending on what they serve.

    3. Number systems and arithmetic

    Four bases appear on every paper: binary (2), octal (8), decimal (10) and hexadecimal (16). The exam asks you to convert a concrete number — so below we convert the same number through every direction, showing every intermediate step.

    Decimal 173 → binary, octal, hex

    Repeatedly divide by the target base and collect remainders bottom-up:

    → Binary173 ÷ 2 = 86 r 1 → 86 ÷ 2 = 43 r 0 → 43 ÷ 2 = 21 r 1 → 21 ÷ 2 = 10 r 1 → 10 ÷ 2 = 5 r 0 → 5 ÷ 2 = 2 r 1 → 2 ÷ 2 = 1 r 0 → 1 ÷ 2 = 0 r 1
    ResultRead remainders bottom-up: 10101101₂
    → Octal173 ÷ 8 = 21 r 5 → 21 ÷ 8 = 2 r 5 → 2 ÷ 8 = 0 r 2
    Result255₈
    → Hex173 ÷ 16 = 10 r 13 = D → 10 ÷ 16 = 0 r 10 = A
    ResultAD₁₆
    Binary ↔ Octal ↔ Hex — the shortcut

    Because 8 = 2³ and 16 = 2⁴, you can group binary digits instead of dividing. Take our binary 10101101:

    → OctalGroup in 3s from right: 10 101 101 → pad left group: 010 101 101 → 255₈ ✓
    → HexGroup in 4s from right: 1010 1101 → A D → AD₁₆ ✓
    Binary arithmetic

    Add 10101101 + 01110010 (173 + 114 = 287):

    Complements

    Subtraction in hardware is done by adding the complement. For an 8-bit number:

    1's complementFlip every bit. For 01110010 (114): 10001101
    2's complement1's complement + 1 = 10001101 + 1 = 10001110
    Check01110010 + 10001110 = 1 00000000 — the carry-out is discarded, leaving 00000000 (zero), confirming they are additive inverses.
    Why2's complement lets the same adder circuit handle both addition and subtraction — no separate subtractor needed.
    Overflow detection

    In signed 2's complement, overflow occurs when two positive numbers produce a negative result (or two negatives produce positive). The rule: overflow = carry into MSB ⊕ carry out of MSB. If these two carries differ, the result is wrong.

    Other codes

    Code Rule Example for decimal 5
    BCD (8421) Each decimal digit → 4 binary bits 0101
    Excess-3 BCD + 0011 1000
    Gray code Adjacent values differ by 1 bit 0111

    BCD is used in financial calculations where decimal rounding must be exact. Gray code prevents glitches in rotary encoders and Karnaugh maps.

    4. Character encoding

    A character encoding maps each symbol to a number. The exam typically asks for a comparison, so here is the timeline and the contrast:

    Encoding Bits / char Characters Use
    ASCII 7 (stored in 8) 128 English-only text, protocols
    Extended ASCII 8 256 Western European accents
    EBCDIC 8 256 IBM mainframes
    Unicode variable 149,813+ Every script, including Bangla
    UTF-81–4 bytes per character. ASCII characters use 1 byte (backward compatible). Bangla uses 3 bytes. Dominant on the web (>98%).
    UTF-162 or 4 bytes. Used internally by Java and Windows. Bangla uses 2 bytes.
    BanglaBijoy uses a non-standard font mapping (not true encoding). Unicode Bangla (U+0980–U+09FF) is the standard — government and banking systems require it.

    5. Memory hierarchy

    Every level trades speed for capacity. The processor needs data in nanoseconds; disk delivers in milliseconds — a million-fold gap. The hierarchy bridges it by keeping frequently used data close to the CPU.

    Type Volatile? Speed Typical size
    SRAM Yes ~1 ns (cache) KB–MB
    DRAM (DDR4/5) Yes ~10 ns GB
    ROM / PROM / EPROM No ~50 ns KB–MB
    EEPROM / Flash No ~25 µs GB–TB
    SRAM vs DRAM. SRAM uses 6 transistors per bit, holds data as long as power is on. DRAM uses 1 transistor + 1 capacitor, must be refreshed every ~64 ms. SRAM is faster → cache; DRAM is denser → main memory.

    6. Storage devices and units

    Storage-unit arithmetic is a near-certain question. The chain is powers of 2 for memory or powers of 10 for disk marketing.

    Binary1 KiB = 2¹⁰ = 1,024 B · 1 MiB = 2²⁰ · 1 GiB = 2³⁰ · 1 TiB = 2⁴⁰
    SI1 KB = 10³ = 1,000 B · 1 MB = 10⁶ · 1 GB = 10⁹ · 1 TB = 10¹²
    RuleUnless stated, use 2¹⁰ = 1024. A "500 GB" HDD = 500 × 10⁹ ÷ 2³⁰ ≈ 465 GiB.
    HDD geometry

    Platters with concentric tracks, each split into sectors (512 B). Same-radius tracks across platters form a cylinder.

    Capacity= cylinders × heads × sectors/track × bytes/sector
    Example10,000 × 8 × 200 × 512 = 8,192,000,000 B ≈ 7.63 GiB
    Medium Type Capacity
    HDD Magnetic 1–20 TB
    SSD (NVMe) Flash 256 GB – 8 TB
    CD / DVD / Blu-ray Optical 700 MB / 4.7 GB / 25 GB
    LTO-9 tape Magnetic 18 TB native

    7. Input and output devices

    The exam asks you to name devices and compare similar ones — especially OCR vs OMR vs MICR.

    Input devices — the comparison the exam wants
    Device Reads Used for
    OCR Printed / handwritten chars Postal sorting, forms
    OMR Pencil marks on fixed positions MCQ sheets, lottery
    MICR Magnetic-ink characters Bank cheques (fast, tamper-proof)
    Barcode / QR 1D bars / 2D matrix Retail, Bangla QR payments
    Biometric Fingerprint, iris, face Authentication, e-KYC
    MICR vs OCRMICR is faster, more accurate and fraud-resistant (magnetic ink survives overwriting). Banks choose MICR for cheques precisely for this tamper resistance.
    Output — monitors and printers
    Type Technology Key point
    CRT → LCD → LED → OLED Phosphor → liquid crystal → LED backlight → self-emitting Each step: thinner, less power, better contrast
    Dot matrix Impact, pin-and-ribbon Multi-part carbon copies
    Inkjet Non-impact, liquid ink Photo quality, costly ink
    Laser Non-impact, toner + heat Fast, crisp text, office standard

    8. Ports, buses and the motherboard

    The system bus has three channels: data bus (the value), address bus (where), control bus (read/write). The address-bus width determines addressable memory:

    FormulaAddressable memory = 2ⁿ bytes, n = address-bus width
    32-bit2³² = 4,294,967,296 B = 4 GiB
    64-bit2⁶⁴ = 16 EiB — far beyond any current physical install
    Port generations
    Port Speed Notes
    USB 2.0 480 Mbps Hi-Speed
    USB 3.0 5 Gbps SuperSpeed, blue port
    USB4 / TB4 40 Gbps Type-C
    HDMI 2.1 48 Gbps Video + audio, 8K
    BIOS vs UEFIBIOS: 16-bit, MBR, 2 TB limit. UEFI: 32/64-bit, GPT, no size limit, Secure Boot.
    BootPower → POST → BIOS/UEFI → bootloader → OS kernel → drivers and services.

    9. Software and translators

    Software divides into system (OS, utilities, drivers, firmware) and application (word processor, browser, banking app). The exam's favourite question in this topic is the translator comparison.

    Translator Input Output Execution Error report Speed
    Assembler Assembly Machine code After full translation All at once Fastest output
    Compiler High-level (C, Java) Machine / bytecode After full translation All at once Slow compile, fast run
    Interpreter High-level (Python) No stored output Line by line Stops at first error Slow run each time
    Java uses both. javac compiles source to bytecode (.class); the JVM then interprets bytecode and JIT-compiles hot paths to native code. This is why Java is called "compile once, run anywhere."
    Language gens1GL: machine code · 2GL: assembly · 3GL: C, Java, Python · 4GL: SQL, MATLAB · 5GL: Prolog, AI
    LicensingGPL: share-alike · MIT: do anything · Apache: patent grant · Proprietary: no source · FOSS: free + open source

    10. Malware and antivirus

    Malware is software written to damage, disrupt or gain unauthorised access. The exam asks you to name the type from a description — so the table below is organised by the distinguishing behaviour.

    Type Distinguishing behaviour
    Virus Attaches to a host file; spreads when the host runs
    Worm Self-replicates over networks — no host file needed
    Trojan Disguised as legitimate software; does not replicate
    Ransomware Encrypts files, demands payment for the key
    Spyware Silently collects user data (keystrokes, browsing)
    Rootkit Hides deep in the OS to maintain persistent access
    Logic bomb Dormant code that triggers on a condition (date, event)
    Adware Forces unwanted advertisements
    Virus sub-types
    Boot sectorInfects the MBR/VBR; runs before the OS loads
    MacroVBA inside Office documents; spreads when document is opened
    PolymorphicEncrypts itself with a different key each copy → defeats signature detection
    MetamorphicRewrites its own code without encryption → even harder to detect
    StealthIntercepts OS calls to hide itself — e.g. shows the original file size
    Antivirus detection
    Technique How it works Limitation
    Signature Matches known byte patterns Cannot detect new (zero-day) malware
    Heuristic Analyses code structure for suspicious patterns False positives
    Behavioural Monitors runtime actions (file encryption, keylogging) Some damage may occur before detection
    Sandboxing Runs suspect code in an isolated environment Slow; malware may detect the sandbox

    Common products: Kaspersky, Norton, Bitdefender, ESET NOD32, McAfee, Avast, AVG, Avira, Trend Micro, Windows Defender.

    11. Ethics and environment

    Brief but examinable: e-waste is discarded electronics containing lead, mercury and cadmium — improper disposal contaminates soil and water. Green computing addresses this through energy-efficient hardware, virtualisation (fewer physical servers), cloud consolidation, proper recycling and e-waste legislation.

    ErgonomicsScreen at arm's length, top of screen at eye level, feet flat, wrists neutral — prevents RSI and eye strain.
    Digital divideThe gap between those with and without access to ICT. In Bangladesh, union digital centres and a2i bridge this gap for rural populations.

    S2 Arrange the following in order from fastest to slowest: HDD, L1 cache, Registers, Main memory, SSD, L2 cache. standard repeat
    OrderRegisters (~0.3 ns) → L1 cache (~1 ns) → L2 cache (~3–10 ns) → Main memory (~50–100 ns) → SSD (~25–100 µs) → HDD (~5–10 ms)
    PatternEach level is roughly 10× slower. Registers are ~10⁷ times faster than HDD.
    S3 A system has a 20-bit address bus and 8-bit data bus. What is the maximum addressable memory? standard repeat
    FormulaMax memory = 2ⁿ × (data bus width / 8) bytes. Here data bus = 8 bits = 1 byte per address, so max = 2²⁰ locations × 1 byte.
    Compute2²⁰ = 1,048,576 bytes
    Answer1 MiB (1,048,576 bytes)
    S4 Differentiate between compiler, interpreter, and assembler. past paper
    Feature Assembler Compiler Interpreter
    Input Assembly language High-level source (C, Java) High-level source (Python)
    Output Machine code Machine code / bytecode No stored output
    Translation Entire program at once Entire program at once Line by line
    Errors Lists all errors Lists all errors Stops at first error
    Execution speed Fastest (direct mapping) Fast (after compilation) Slowest (re-translates each run)
    Re-compilation No (unless source changes) No (unless source changes) Every time

    Key insight: Java uses both — javac compiles to bytecode, then the JVM interprets or JIT-compiles to native code at runtime.

    S5 A program starts deleting files after a specific date. What type of malware is this? Explain three other types. practice

    This is a logic bomb — dormant malicious code that triggers when a predefined condition (here, a date) is met.

    VirusAttaches to a host program; replicates when the host executes. Cannot spread on its own without a carrier file.
    WormSelf-replicating across networks without needing a host file. Example: Stuxnet spread via USB and network shares.
    TrojanDisguised as legitimate software (e.g. a "free game"). Does not replicate, but provides backdoor access.

    S7 A disk has 5,000 cylinders, 4 heads, 400 sectors per track, and a sector size of 512 bytes. Calculate the disk capacity in GiB. standard repeat

    S8 Compare SRAM and DRAM in terms of speed, cost, use, and need for refresh. past paper
    Feature SRAM DRAM
    Circuit 6 transistors per bit (flip-flop) 1 transistor + 1 capacitor per bit
    Speed ~1 ns (faster) ~10 ns (slower)
    Cost per bit Higher (more transistors) Lower (denser)
    Refresh Not needed Needs refresh every ~64 ms
    Primary use CPU cache (L1, L2, L3) Main memory (RAM sticks)
    Density Low (large area per bit) High (small area per bit)

    Bottom line: SRAM's speed makes it ideal for cache but its cost limits it to small sizes. DRAM's density makes it practical for gigabytes of main memory despite needing periodic refresh.

    10 questions

    Original questions written in the same style and difficulty as the real papers. Every one has a full worked solution.

    P1 Convert 0.6875₁₀ to binary (up to 4 fractional bits).
    MethodMultiply by 2 and collect integer parts top-down:
    Step 10.6875 × 2 = 1.375
    Step 20.375 × 2 = 0.75
    Step 30.75 × 2 = 1.5
    Step 40.5 × 2 = 1.0 (terminates)
    Answer0.1011₂. Check: ½ + ⅛ + 1⁄16 = 0.5 + 0.125 + 0.0625 = 0.6875 ✓
    P2 Convert the binary sequence 0110 to Gray code. Then convert Gray code 1011 back to binary.
    Binary → Gray
    RuleMSB stays. Each subsequent bit = current binary bit XOR previous binary bit.
    TraceBinary 0110: G₃=0, G₂=0⊕1=1, G₁=1⊕1=0, G₀=1⊕0=1
    Gray0101
    Gray → Binary
    RuleMSB stays. Each subsequent bit = current Gray bit XOR previous binary (output) bit.
    TraceGray 1011: B₃=1, B₂=1⊕0=1, B₁=1⊕1=0, B₀=0⊕1=1
    Binary1101 (= 13₁₀)
    P3 Name the five computer generations. For each, state the switching technology and give one example machine.
    Gen Switch Example
    1st (1940–56) Vacuum tube ENIAC
    2nd (1956–63) Transistor IBM 7094
    3rd (1964–71) IC (SSI/MSI) IBM 360
    4th (1971–now) Microprocessor (VLSI) Intel 4004
    5th (now–future) AI / parallel processing IBM Watson
    P4 How long does it take to transfer a 2 GiB file over USB 3.0 (5 Gbps)? Assume no overhead.
    Size2 GiB = 2 × 2³⁰ bytes = 2 × 2³⁰ × 8 bits = 2³⁴ bits = 17,179,869,184 bits
    Rate5 Gbps = 5 × 10⁹ bps
    Time17,179,869,184 ÷ 5,000,000,000
    Answer≈ 3.44 seconds
    P5 Describe the boot process of a computer from power-on to OS loading.
    Step 1Power supply sends a "power good" signal once voltages stabilise.
    Step 2POST (Power-On Self-Test) checks CPU, RAM, GPU, keyboard. Failures produce beep codes.
    Step 3BIOS/UEFI loads from ROM/flash. Initialises hardware, reads boot order from CMOS/NVRAM.
    Step 4Bootloader (GRUB or Windows Boot Manager) is loaded from the boot device's MBR/EFI partition.
    Step 5OS kernel is loaded into RAM. Kernel initialises drivers, file systems, and system services.
    Step 6Login screen appears. User-space processes start (shell, GUI, services).
    P6 What is the ASCII value of 'A'? What is 'A' + 5 in ASCII? What is the difference between 'a' and 'A' in ASCII?
    'A'ASCII 65 (binary: 01000001)
    'A' + 565 + 5 = 70 = 'F'
    'a' − 'A'97 − 65 = 32. To convert uppercase → lowercase, add 32. This 32 = 2⁵, which means only bit 5 differs.
    P7 A file is 750 MB. Can it fit on a CD (700 MB)? On a single-layer DVD (4.7 GB)? Calculate remaining space on the DVD.
    CD750 MB > 700 MB → No, does not fit.
    DVD750 MB < 4,700 MB → Yes, fits.
    Remaining4,700 − 750 = 3,950 MB ≈ 3.86 GB remaining.
    P8 Differentiate between impact and non-impact printers. Name two examples of each.
    Feature Impact Non-impact
    Mechanism Physical strike (pin/hammer hits ribbon onto paper) No contact (ink spray, toner heat, or thermal)
    Noise Loud Quiet
    Carbon copies Yes (multipart forms) No
    Speed Slow Fast (laser) or medium (inkjet)

    P9 Add the signed 8-bit numbers +120 and +15 using 2's complement. Does overflow occur?
    Given+120 = 01111000 · +15 = 00001111
    Add01111000 + 00001111 = 10000111
    Check MSBResult MSB = 1 → interpreted as negative (−121 in 2's complement)
    Overflow?Carry into MSB = 1, carry out of MSB = 0 → 1 ⊕ 0 = 1 → overflow detected
    Explanation120 + 15 = 135, but 8-bit signed range is −128 to +127. Since 135 > 127, the result overflows. The hardware produces the wrong answer (−121).
    P10 What is e-waste? List four ways to practise green computing.

    E-waste is discarded electronic equipment — computers, phones, printers — that contain hazardous materials (lead, mercury, cadmium, BFRs). Improper disposal contaminates soil, water and air.

    1Energy-efficient hardware — use Energy Star certified devices, enable power management (sleep/hibernate).
    2Virtualisation — run multiple virtual servers on one physical machine, reducing hardware count by 10–20×.
    3Proper recycling — certified e-waste recyclers recover metals and safely handle toxics. Legislation: EU WEEE Directive, Basel Convention.
    4Cloud consolidation — shared data centres achieve higher utilisation rates than on-premise servers, reducing per-workload energy.
