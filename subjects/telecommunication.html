    1. Signals and spectra

    Every piece of information — voice, video, sensor data — must ride on a signal to travel from source to destination. A signal is simply a pattern of voltage, current or electromagnetic energy that changes over time. Understanding the two families of signals is the starting point for the rest of this subject.

    An analog signal varies continuously — it can take any value within a range. A sine wave is the simplest example, described by three parameters:

    s(t) = A sin(2πft + φ)
    A = amplitude (peak voltage), f = frequency (Hz), φ = phase (radians)

    A digital signal takes only a finite set of discrete values — typically two levels (0 and 1). It changes abruptly between levels. Digital signals are more noise-resistant because the receiver only needs to distinguish between two levels, not an infinite continuum.

    Bandwidth is the range of frequencies a signal occupies: BW = fmax − fmin. A voice channel occupies roughly 300–3400 Hz, giving a bandwidth of 3100 Hz. A composite signal is the sum of multiple sine waves at different frequencies — Fourier analysis decomposes any periodic signal into its sinusoidal components.

    The time domain shows amplitude vs time; the frequency domain shows amplitude vs frequency. They are two views of the same signal — Fourier transforms convert between them. A perfect square wave needs infinitely many harmonics; bandwidth-limiting it rounds the edges.

    2. Analog-to-digital conversion

    To transmit analog data (voice, temperature) over a digital system, we convert it into bits. The standard process is Pulse Code Modulation (PCM), which has three steps: sampling, quantization and encoding.

    Step 1 — Sampling. Take snapshots of the analog signal at regular intervals. The Nyquist theorem states that the sampling rate must be at least twice the highest frequency in the signal to reconstruct it perfectly:

    fs ≥ 2 × fmax
    fs = sampling rate, fmax = highest frequency component

    For telephone voice (fmax = 4000 Hz), the sampling rate is 2 × 4000 = 8000 samples/s.

    Step 2 — Quantization. Each sample's amplitude is rounded to the nearest of L discrete levels. With n bits per sample, L = 2n. The difference between the true amplitude and the quantized value is quantization noise.

    SQNR (dB) = 6.02n + 1.76
    Each extra bit improves SNR by ~6 dB

    Step 3 — Encoding. Convert each quantized level to an n-bit binary code. The output bit rate is:

    Bit rate = fs × n
    = 8000 × 8 = 64,000 bps = 64 kbps
    This is the standard telephone PCM rate

    Delta modulation is a simpler alternative: instead of encoding the full amplitude, it encodes only the change from the previous sample — 1 if the signal went up, 0 if it went down. It uses only 1 bit per sample but suffers from slope overload (signal changes faster than the step size) and granular noise (signal is flat but the output oscillates). Adaptive delta modulation varies the step size to reduce both.

    The Nyquist rate is a hard lower bound — sampling below it causes aliasing, where high frequencies masquerade as low ones, and no amount of processing can recover the original. In practice, an anti-aliasing filter removes frequencies above fmax before sampling.

    3. Digital-to-analog conversion

    A DAC converts a binary number into a proportional analog voltage. The key specification is resolution — the smallest voltage step the DAC can produce.

    Take a concrete example: a 12-bit DAC with a reference voltage of 3.3 V (this exact question appeared on 04/10/2024).

    Resolution = Vref / (2n − 1)
    = 3.3 / (212 − 1)
    = 3.3 / 4095
    = 0.000806 V ≈ 0.806 mV

    The output for any digital input D (0 to 2n − 1) is:

    Vout = D × Resolution = D × Vref / (2n − 1)

    Two common DAC architectures:

    Weighted-resistor DAC uses resistors in powers of 2 (R, 2R, 4R, 8R…). Each bit switches its resistor into the summing network. Simple but impractical for high resolution because the resistor ratio gets extreme — a 12-bit DAC needs R to 2048R, and matching such different resistors precisely is difficult.

    R-2R ladder DAC uses only two resistor values: R and 2R. The ladder network naturally produces binary-weighted currents through voltage division. This is the practical choice because manufacturing two matched values is far easier than matching a range.

    Settling time is how long the DAC output takes to reach its final value within a specified tolerance after a digital input change. Faster settling time allows higher conversion rates.

    The formula uses (2n − 1) in the denominator, not 2n. The reason: the maximum digital input (all 1s = 2n − 1) should produce exactly Vref, so there are 2n − 1 steps between 0 and Vref.

    4. Modulation

    Modulation maps data onto a carrier wave so it can travel over a channel. The carrier is a high-frequency sine wave s(t) = A sin(2πft + φ), and modulation changes one of its three parameters — amplitude, frequency or phase — according to the data.

    Analog modulation — the modulating signal is analog:

    TypeWhat variesBandwidthNotes
    AMAmplitude2B (B = message BW)Simple but noise-sensitive; used in AM radio
    FMFrequency2(Δf + B)Better noise immunity; Δf = peak frequency deviation
    PMPhase2(Δφ × fm + B)Similar to FM; carrier phase tracks signal amplitude

    Digital modulation — the modulating signal is digital bits:

    SchemeWhat variesBits/symbolBW needed
    ASKAmplitude (on/off)1B = baud rate
    FSKTwo frequencies1B = baud + (f2 − f1)
    BPSKPhase (0° or 180°)1B = baud rate
    QPSKPhase (4 states)2B = baud rate
    8-PSKPhase (8 states)3B = baud rate
    16-QAMAmplitude + phase4B = baud rate
    64-QAMAmplitude + phase6B = baud rate

    The relationship between bit rate and baud rate:

    Bit rate = Baud rate × log2(L)
    L = number of signal levels (constellation points)

    Take 16-QAM at 10,000 baud: bit rate = 10,000 × log2(16) = 10,000 × 4 = 40,000 bps. The constellation diagram for 16-QAM is a 4×4 grid where each point encodes 4 bits. Higher-order QAM packs more bits per symbol but requires a better SNR — the points are closer together and noise can cause the receiver to decode the wrong point.

    Baud rate is symbols per second; bit rate is bits per second. They are equal only when each symbol carries exactly 1 bit (ASK, FSK, BPSK). For QPSK onwards, bit rate > baud rate.

    5. Channel capacity

    Two theorems set the speed limit for any communication channel. They answer the same question — how many bits per second can we push through? — but under different assumptions.

    Nyquist bit rate (noiseless channel):

    C = 2B log2(L)
    B = bandwidth (Hz), L = number of signal levels

    Take a 3-kHz voice channel with 4 signal levels: C = 2 × 3000 × log2(4) = 2 × 3000 × 2 = 12,000 bps.

    Shannon capacity (noisy channel):

    C = B log2(1 + SNR)
    SNR = signal-to-noise ratio (linear, not dB)

    If the same 3-kHz channel has SNR = 30 dB, first convert to linear: SNRlinear = 1030/10 = 1000. Then C = 3000 × log2(1001) ≈ 3000 × 9.97 = 29,901 bps.

    Shannon's limit is an absolute upper bound — no coding scheme can exceed it. In practice, the two theorems are used together: Nyquist tells you how many levels to use, and Shannon tells you the maximum bit rate regardless of levels. If Nyquist gives a higher number than Shannon, the noise makes that many levels impractical.

    FeatureNyquistShannon
    AssumesNoiseless channelNoisy channel (Gaussian noise)
    VariablesBandwidth, signal levelsBandwidth, SNR
    ResultMaximum baud rate × bits/symbolAbsolute upper bound on bit rate
    UseChoose signal levelsCheck if those levels are achievable
    A common exam pattern: "given BW and SNR, find how many signal levels are needed." Use Shannon to find the max bit rate, then Nyquist to solve for L: L = 2C/(2B). If L comes out fractional, round down — you cannot use half a level.

    6. Multiplexing

    Multiplexing combines multiple signals onto a single channel to share its capacity. There are three fundamental approaches.

    FDM (Frequency Division Multiplexing) gives each signal its own frequency band within the channel. Guard bands separate adjacent signals to prevent interference. Used in analog TV, FM radio and ADSL. A channel of bandwidth B carrying N signals each of bandwidth b with guard band g needs: B ≥ N × b + (N − 1) × g.

    TDM (Time Division Multiplexing) gives each signal its own time slot in a repeating frame. Two variants:

    • Synchronous TDM — fixed slots allocated whether or not a source has data. The T1 frame carries 24 channels × 8 bits + 1 framing bit = 193 bits at 8000 frames/s = 1.544 Mbps.
    • Statistical TDM — slots allocated only to active sources. More efficient, but needs address fields in each slot to identify the source.

    WDM (Wavelength Division Multiplexing) is FDM applied to optical fibre — each signal uses a different wavelength (colour) of light. DWDM (Dense WDM) can carry 80+ channels on a single fibre.

    CDMA (Code Division Multiple Access) lets all sources transmit simultaneously on the same frequency. Each source is assigned a unique chip code (a sequence of +1 and −1). Codes are orthogonal: the dot product of any two different codes is zero, so the receiver can extract its signal by multiplying the composite and summing.

    SchemeDividesGuardUsed in
    FDMAFrequencyGuard bands1G (AMPS), FM radio
    TDMATimeGuard time2G (GSM)
    CDMACodeOrthogonal codes3G (WCDMA, CDMA2000)
    OFDM (Orthogonal Frequency Division Multiplexing) is the dominant scheme in 4G and Wi-Fi. It splits a wide channel into many narrow subcarriers, each carrying a low-rate stream. The subcarriers overlap but are orthogonal, so there are no guard bands — spectral efficiency is much higher than plain FDM.

    7. Combinational logic

    A combinational circuit's output depends only on its current inputs — it has no memory. The building blocks are multiplexers, decoders, encoders and adders.

    Multiplexer (MUX) — a 2n:1 MUX has 2n data inputs, n select lines and 1 output. It routes the selected input to the output. The key exam use is implementing Boolean functions with a MUX.

    Example: implement F(A, B, C) = Σm(1, 2, 4, 7) with an 8:1 MUX. Connect A, B, C to the select lines S2, S1, S0. For each minterm in the function, connect that data input to 1; for every other, connect to 0:

    InputABCMintermIn F?Di
    D0000m0No0
    D1001m1Yes1
    D2010m2Yes1
    D3011m3No0
    D4100m4Yes1
    D5101m5No0
    D6110m6No0
    D7111m7Yes1

    Implementing with a smaller MUX: to implement a 3-variable function with a 4:1 MUX (one fewer select line), connect A and B to S1, S0. Group minterms by AB: for each group, the data input is expressed in terms of C:

    ABC=0C=1Di
    00m0=0m1=1C
    01m2=1m3=0C̄
    10m4=1m5=0C̄
    11m6=0m7=1C

    Decoders and encoders. An n-to-2n decoder activates exactly one of 2n outputs based on the n-bit input. A priority encoder does the reverse — it takes 2n inputs and outputs the binary code of the highest-priority active input plus a valid bit.

    Adders. A half adder adds two bits producing Sum = A ⊕ B and Carry = A · B. A full adder adds three bits (A, B, Cin) producing Sum = A ⊕ B ⊕ Cin and Cout = AB + BCin + ACin. A ripple-carry adder chains n full adders — simple but slow because each carry depends on the previous stage. A carry-lookahead adder computes all carries in parallel using generate (G = AB) and propagate (P = A ⊕ B) signals.

    A decoder with an enable input can implement any Boolean function: connect the enable to 1, the variables to the inputs, and OR the decoder outputs corresponding to the minterms. A 3-to-8 decoder plus one OR gate implements any 3-variable function.

    8. Sequential logic

    A sequential circuit's output depends on current inputs and stored state — it has memory. The basic storage element is the flip-flop.

    Latches vs flip-flops. A latch is level-triggered (transparent while the enable is high). A flip-flop is edge-triggered (captures data only on the rising or falling clock edge). Flip-flops are preferred in synchronous design because they eliminate timing hazards from racing conditions.

    The four standard flip-flops — each with its characteristic table and excitation table (the exam frequently asks for both):

    TypeInputsCharacteristicExcitation (Q→Q+)
    SR S, R S=0,R=0→Q; S=0,R=1→0; S=1,R=0→1; S=1,R=1→invalid 0→0: S=0,R=×; 0→1: S=1,R=0; 1→0: S=0,R=1; 1→1: S=×,R=0
    D D Q+ = D 0→0: D=0; 0→1: D=1; 1→0: D=0; 1→1: D=1
    JK J, K J=0,K=0→Q; J=0,K=1→0; J=1,K=0→1; J=1,K=1→Q̄ (toggle) 0→0: J=0,K=×; 0→1: J=1,K=×; 1→0: J=×,K=1; 1→1: J=×,K=0
    T T T=0→Q; T=1→Q̄ (toggle) 0→0: T=0; 0→1: T=1; 1→0: T=1; 1→1: T=0

    The race-around condition occurs in JK flip-flops when J=K=1: if the latch is level-triggered, the output toggles continuously while the clock is high. The master-slave design fixes this — the master latch captures on clock-high, the slave transfers on clock-low, so only one toggle occurs per cycle.

    Registers are groups of flip-flops sharing a clock. Four shift types: SISO (serial in, serial out), SIPO, PISO, PIPO. A universal shift register can do all four.

    Counters. An asynchronous (ripple) counter chains T flip-flops where each output clocks the next — simple but the propagation delay accumulates. A synchronous counter uses a common clock — all flip-flops toggle simultaneously, so it is faster and glitch-free. Types: up, down, up/down, mod-N (counts 0 to N−1 and resets), ring (one-hot circular), Johnson (twisted ring).

    Designing a synchronous counter — mod-6 counter (counts 0→1→2→3→4→5→0) using JK flip-flops:

    1. Determine the number of flip-flops

      Need to count 6 states (0–5). Minimum flip-flops = ⌈log2(6)⌉ = 3. Call them Q2Q1Q0.

    2. Write the state table
      PresentQ2Q1Q0NextQ2+Q1+Q0+
      00001001
      10012010
      20103011
      30114100
      41005101
      51010000
    3. Use excitation table to find J, K for each flip-flop

      For each transition Q→Q+, look up the required JK inputs. States 6 and 7 (110, 111) are don't-cares.

    4. Simplify using K-maps and draw the circuit

      Each J and K input is a function of Q2, Q1, Q0. K-maps give the minimal expressions.

    Mealy vs Moore machines. A Moore machine's output depends only on the current state — outputs are labelled on state circles. A Mealy machine's output depends on the current state and input — outputs are labelled on transition arrows. Moore machines typically need more states but are easier to design; Mealy machines respond one clock cycle faster.

    The excitation table is the reverse of the characteristic table: given the transition you want (Q→Q+), it tells you what inputs to apply. This reversal is the entire method for designing sequential circuits from state tables.

    9. Optical fibre

    Optical fibre transmits data as pulses of light through a glass or plastic strand. The principle is total internal reflection — light hitting the core-cladding boundary at an angle greater than the critical angle bounces back into the core instead of escaping.

    The fibre has three layers: the core (carries light, higher refractive index), the cladding (lower refractive index, reflects light back), and the buffer coating (mechanical protection).

    Two fibre types:

    FeatureSingle-modeMultimode
    Core diameter8–10 µm50–62.5 µm
    Light sourceLaserLED
    ModesOne (axial ray only)Many (rays at different angles)
    DispersionVery lowHigher (modal dispersion)
    DistanceUp to 100+ kmUp to ~2 km
    CostHigherLower
    UseLong-haul, undersea cablesLAN, data centres

    Multimode fibre comes in two index profiles: step-index (sharp boundary between core and cladding — causes more modal dispersion) and graded-index (refractive index gradually decreases from the centre — rays taking longer paths travel through lower-index material and thus travel faster, reducing dispersion).

    Advantages over copper: immunity to EMI, much higher bandwidth, lower attenuation, lighter, smaller, secure (difficult to tap without detection), no electrical hazard. Disadvantages: fragile, difficult to splice, more expensive termination equipment.

    Modal dispersion is why multimode fibre has shorter range: rays entering at different angles take different path lengths and arrive at different times, smearing the pulse. Single-mode fibre eliminates this by making the core so narrow that only the axial ray fits.

    10. Wireless and carrier networks

    Satellite communication uses a transponder in orbit that receives an uplink signal, amplifies it, shifts its frequency and retransmits it as the downlink. Three orbit classes:

    OrbitAltitudeLatencyCoverageExample
    GEO35,786 km~540 ms round-trip1/3 of Earth per satelliteVSAT, DTH TV
    MEO2,000–35,786 km~100 msRegionalGPS, GLONASS
    LEO160–2,000 km~20–40 msSmall footprint, needs constellationStarlink, Iridium

    Cellular networks divide a coverage area into cells, each served by a base station. Adjacent cells use different frequencies to avoid interference; the pattern repeats in a cluster. Smaller cells mean more capacity (frequency reuse) but more handoffs.

    GenPeriodTechnologyData rateKey feature
    1G1980sFDMA, analog (AMPS)Voice onlyFirst mobile telephony
    2G1990sTDMA/CDMA, digital (GSM)~14.4 kbpsSMS, digital voice
    3G2000sWCDMA, CDMA20002–42 MbpsMobile internet, video calls
    4G2010sOFDMA (LTE, LTE-A)100 Mbps–1 GbpsAll-IP, streaming
    5G2020sOFDMA, mmWave, MIMO1–20 GbpsUltra-low latency, IoT, network slicing

    GSM architecture has three subsystems: the Mobile Station (MS = phone + SIM), the Base Station Subsystem (BTS + BSC), and the Network Subsystem (MSC, VLR, HLR, AuC, EIR). CDMA architecture replaces BSC/BTS with a Base Station Controller and uses soft handoff (connected to multiple base stations simultaneously during handover).

    Legacy carrier networks: PSTN (circuit-switched voice), ISDN (digital voice and data over copper), DSL family (ADSL: asymmetric, faster download; VDSL: very high rate), cable modem (HFC — hybrid fibre-coaxial), SONET/SDH (synchronous optical transport, ring topology for resilience).

    Frequency reuse factor N (cluster size) = i2 + ij + j2
    Example: i=2, j=1 → N = 4 + 2 + 1 = 7
    If system has 490 duplex channels and N = 7:
    Channels per cell = 490 / 7 = 70 channels/cell
    Smaller N → more channels per cell but higher co-channel interference
    Each cellular generation roughly maps to a multiple-access technology: 1G = FDMA, 2G = TDMA, 3G = CDMA, 4G/5G = OFDMA. This is the single-line summary the exam expects.

    Solved past questions

    10 questions
    S1 A 12-bit DAC has a reference voltage of 3.3 V. Find the resolution and the output voltage for digital input 1010 0000 0000. BB AD ICT, 04/10/2024 — adapted

    Given: n = 12 bits, Vref = 3.3 V, D = 1010 0000 00002

    1. Convert digital input to decimal
      D = 1×211 + 0 + 1×29 + 0 + … = 2048 + 512 = 2560
    2. Calculate resolution
      Resolution = Vref / (2n − 1) = 3.3 / (4096 − 1) = 3.3 / 4095
      = 0.000806 V ≈ 0.806 mV
    3. Calculate output voltage
      Vout = D × Resolution = 2560 × 0.000806
      = 2.064 V

    Final answer: Resolution = 0.806 mV; Vout for input 1010 0000 0000 = 2.064 V.

    S2 A voice channel has bandwidth 4 kHz and SNR = 30 dB. Find the channel capacity using Shannon's theorem, then determine the minimum number of signal levels needed using Nyquist. standard repeat

    Given: B = 4000 Hz, SNR = 30 dB

    1. Convert SNR from dB to linear
      SNRlinear = 10SNRdB/10 = 1030/10 = 103 = 1000
    2. Apply Shannon's theorem
      C = B × log2(1 + SNR) = 4000 × log2(1001)
      = 4000 × 9.97
      ≈ 39,860 bps
    3. Use Nyquist to find signal levels
      C = 2B × log2(L)
      39,860 = 2 × 4000 × log2(L)
      log2(L) = 39,860 / 8000 = 4.98
      L = 24.98 ≈ 31.6
      Round down: L = 32 signal levels (5 bits/symbol)

    Final answer: Shannon capacity ≈ 39,860 bps. Minimum signal levels = 32 (which gives exactly 2 × 4000 × 5 = 40,000 bps — just above the Shannon limit, so 32 is achievable).

    S3 Calculate the PCM bit rate for CD-quality audio (44.1 kHz sampling, 16 bits per sample, stereo). standard repeat

    Given: fs = 44,100 Hz, n = 16 bits/sample, channels = 2 (stereo)

    1. Calculate per-channel bit rate
      Bit rate per channel = fs × n = 44,100 × 16 = 705,600 bps
    2. Calculate stereo bit rate
      Total bit rate = 705,600 × 2 = 1,411,200 bps
      = 1.4112 Mbps
    3. Storage for 1 minute
      = 1,411,200 × 60 / 8 = 10,584,000 bytes ≈ 10.09 MB/min

    Final answer: CD-quality audio requires 1.4112 Mbps, or about 10.09 MB per minute uncompressed.

    S6 Give the characteristic table and excitation table for a JK flip-flop. Why does the master-slave design solve the race-around problem? standard repeat

    Characteristic table (given J, K → find Q+):

    JKQ+Operation
    00QNo change
    010Reset
    101Set
    11Q̄Toggle

    Excitation table (given Q→Q+ → find J, K needed):

    QQ+JK
    000×
    011×
    10×1
    11×0

    Race-around problem: When J=K=1 and clock is HIGH, a level-triggered JK latch toggles continuously — the output feeds back and triggers another toggle within the same clock pulse. The master-slave solution uses two latches: the master captures J, K on clock-HIGH (with Q isolated), then the slave transfers on clock-LOW. Since the master is isolated when the slave updates, only one toggle occurs per cycle.

    S8 A T1 line carries 24 voice channels using synchronous TDM. Calculate the frame size, frame rate and total bit rate. standard repeat

    Given: 24 channels, 8 bits/sample/channel, 8000 frames/s (from Nyquist: voice bandwidth 4 kHz → fs = 8000 Hz)

    1. Frame size
      Data bits = 24 × 8 = 192 bits
      + 1 framing bit for synchronization
      Frame size = 193 bits
    2. Total bit rate
      Bit rate = 193 × 8000 = 1,544,000 bps = 1.544 Mbps
    3. Duration of one frame
      Frame duration = 1 / 8000 = 125 µs

    Final answer: Frame = 193 bits, sent at 8000 frames/s, giving 1.544 Mbps. Each frame lasts 125 µs.

    S9 Design a mod-4 synchronous up-counter using T flip-flops. Draw the state table and find the T inputs. standard repeat

    A mod-4 counter counts 0→1→2→3→0. It needs 2 flip-flops: Q1Q0.

    1. State table with T excitations

      For a T flip-flop: if Q changes, T=1; if Q stays, T=0.

      Present Q1Q0Next Q1+Q0+T1T0
      000101
      011011
      101101
      110011
    2. Derive T inputs
      T0 = 1 (always toggles — it is the LSB)
      T1 = Q0 (toggles only when Q0 = 1)

      This is the standard binary counter pattern: each bit toggles when all lower bits are 1.

    S10 Compare Mealy and Moore machines. Give a brief example of each. standard repeat
    FeatureMooreMealy
    Output depends onCurrent state onlyCurrent state + current input
    Output label onState (circle)Transition (arrow)
    Output changesOnly with state change (on clock edge)Immediately with input change
    Number of statesTypically moreTypically fewer
    Output glitchesGlitch-free (synchronous)Possible (depends on input timing)

    Moore example: a sequence detector for "11" that outputs 1 when the last two inputs were both 1. States: S0 (no 1 seen), S1 (one 1 seen), S2 (two 1s seen, output=1).

    Mealy example: the same detector needs only two states: S0 and S1. In S1, if input=1, output=1 (labelled on the transition).

    Equivalence: every Moore machine has an equivalent Mealy machine with ≤ the same number of states, and vice versa (though Mealy→Moore may add states).

    Practice questions

    10 questions
    P1 A telephone channel has bandwidth 3.1 kHz and SNR = 36 dB. Find the Shannon capacity and the maximum number of signal levels Nyquist allows. practice

    Given: B = 3100 Hz, SNR = 36 dB

    1. Convert SNR
      SNRlinear = 1036/10 = 103.6 ≈ 3981
    2. Shannon capacity
      C = 3100 × log2(3982) = 3100 × 11.96
      ≈ 37,076 bps
    3. Signal levels from Nyquist
      37,076 = 2 × 3100 × log2(L)

    DistanceShorterLonger

    Why less dispersion: In graded-index fibre, rays taking longer geometric paths travel through regions of lower refractive index, where light speed is higher (v = c/n). The speed increase compensates for the longer distance, so all modes arrive at nearly the same time. In step-index, all rays travel at the same speed (same n in the core), so the longer paths genuinely take longer.

    P10 Explain delta modulation and its two noise types. How does adaptive delta modulation improve on it? practice

    Delta modulation (DM) encodes the difference between consecutive samples instead of the absolute value. The output is 1 bit per sample: 1 if the signal increased, 0 if it decreased. The receiver reconstructs by stepping up or down by a fixed step size δ.

    Two noise types:

    • Slope overload noise — when the signal changes faster than δ per sample period. The staircase output cannot keep up, causing distortion. Occurs with high-frequency or steep signals.
    • Granular noise — when the signal is relatively flat. The output oscillates around the true value, toggling ±δ even though the signal isn't changing. Occurs with low-frequency or quiet signals.

    The dilemma: increasing δ reduces slope overload but increases granular noise; decreasing δ does the reverse.

    Adaptive delta modulation (ADM) solves this by varying the step size dynamically. When consecutive outputs are the same (all 1s or all 0s — indicating slope overload), the step size increases. When they alternate (1010 — indicating granular noise), the step size decreases. This adapts to both steep and flat regions of the signal.
