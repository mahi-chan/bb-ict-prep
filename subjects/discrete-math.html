    Discrete Math

    The exam tests calculation-heavy topics: truth-table proofs, permutation/combination counting, Bayes' theorem, graph colouring, Boolean simplification via K-maps, DFA/NFA construction, and modular arithmetic. Every section below walks through concrete worked examples.

    1. Propositional logic

    A proposition is a statement that is either true or false. Compound propositions use connectives:

    ConnectiveSymbolTrue when
    NOT (negation)¬pp is false
    AND (conjunction)p ∧ qBoth true
    OR (disjunction)p ∨ qAt least one true
    Implicationp → q¬p ∨ q (false only when p=T, q=F)
    Biconditionalp ↔ qBoth same value
    XORp ⊕ qExactly one true

    Key equivalences (exam favourites):

    p → q ≡ ¬p ∨ q ≡ ¬q → ¬p (contrapositive)
    ¬(p ∧ q) ≡ ¬p ∨ ¬q (De Morgan)
    ¬(p ∨ q) ≡ ¬p ∧ ¬q (De Morgan)
    p ↔ q ≡ (p → q) ∧ (q → p)

    A tautology is always true (e.g. p ∨ ¬p). A contradiction is always false (e.g. p ∧ ¬p). A contingency is neither.

    Two expressions are logically equivalent if they have the same truth table. Prove equivalence by constructing the truth table or by algebraic manipulation using the laws above.

    Implication is the most counter-intuitive connective: "if pigs fly, then 2+2=5" is true because the premise is false. The only way an implication is false is when the hypothesis holds but the conclusion doesn't.

    2. Proof techniques

    The exam rarely asks you to write a formal proof, but it tests whether you can identify which technique applies and trace through one. The main techniques:

    TechniqueStructureWhen to use
    Direct proofAssume p, derive qProving p → q straightforwardly
    ContrapositiveAssume ¬q, derive ¬pWhen direct path is blocked
    ContradictionAssume ¬(statement), derive absurdityProving existence, irrationality
    InductionBase case + inductive stepProving ∀n ≥ n₀: P(n)
    Pigeonholen+1 items in n boxes → some box has ≥ 2Existence proofs about allocation

    Mathematical induction — the exam-favourite proof:

    1. Base case: prove P(1) (or P(0))

      Substitute the smallest value and verify the claim holds.

    2. Inductive hypothesis: assume P(k) holds for some k ≥ 1

      This is what you get to use — the assumption.

    3. Inductive step: prove P(k+1) using P(k)

      Show the claim extends from k to k+1.

    Example: prove 1 + 2 + … + n = n(n+1)/2.

    Base: n=1 → 1 = 1(2)/2 = 1 ✓
    Assume: 1+2+…+k = k(k+1)/2
    Prove k+1: [k(k+1)/2] + (k+1) = (k+1)(k+2)/2
    LHS = (k+1)[k/2 + 1] = (k+1)(k+2)/2 = RHS ✓
    The induction step is where most students slip: you must actually use the inductive hypothesis P(k) in deriving P(k+1). If your proof doesn't reference the assumption, it is not an induction — and it is probably wrong.

    3. Set theory

    A set is an unordered collection of distinct elements. Key operations:

    OperationSymbolResult
    UnionA ∪ BElements in A or B (or both)
    IntersectionA ∩ BElements in both A and B
    DifferenceA − BElements in A but not B
    ComplementA′ or ĀElements in U not in A
    Symmetric diff.A ⊕ B(A − B) ∪ (B − A)
    Cartesian productA × BAll ordered pairs (a,b)
    Power setP(A)Set of all subsets; |P(A)| = 2|A|

    Inclusion-exclusion principle (the counting formula that appears in every exam):

    |A ∪ B| = |A| + |B| − |A ∩ B|
    |A ∪ B ∪ C| = |A|+|B|+|C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|

    Relations: a relation R on A is a subset of A × A. Properties: reflexive (aRa ∀a), symmetric (aRb → bRa), transitive (aRb ∧ bRc → aRc), antisymmetric (aRb ∧ bRa → a=b). An equivalence relation is reflexive, symmetric and transitive — it partitions the set into equivalence classes.

    Functions: injective (one-to-one, distinct inputs → distinct outputs), surjective (onto, every element in codomain is hit), bijective (both — implies |A| = |B|).

    Inclusion-exclusion is the bridge between set theory and combinatorics. Most "how many students study X or Y" questions are solved by this formula.

    4. Combinatorics

    Counting problems form a large chunk of the exam. The fundamental formulas:

    Permutation: P(n,r) = n!/(n−r)!   [order matters]
    Combination: C(n,r) = n!/[r!(n−r)!]   [order doesn't matter]

    Decision framework: (1) Does order matter? Yes → permutation. No → combination. (2) Is repetition allowed? If yes, multiply by replacement factor.

    TypeFormulaExample
    Perm. without rep.n!/(n−r)!Arrange 3 of 10 people in a line
    Perm. with rep.nr4-digit PIN (0-9): 10⁴
    Comb. without rep.C(n,r)Choose 3 of 10 people for a committee
    Comb. with rep.C(n+r−1, r)Buy 5 fruits from 3 types

    Permutations with identical objects: n objects where n₁ are alike, n₂ are alike, etc.: n!/(n₁! × n₂! × …).

    Example: How many ways to arrange the letters in "MISSISSIPPI"?

    Total letters: 11 (M=1, I=4, S=4, P=2)
    = 11!/(1! × 4! × 4! × 2!)
    = 39916800/(1 × 24 × 24 × 2)
    = 39916800/1152 = 34,650
    Many exam counting problems have a constraint ("no two X adjacent", "at least one Y"). The technique: count the unconstrained total minus the complementary count. "At least one" = total − "none".

    5. Probability

    Basic probability: P(E) = |E|/|S| for equally likely outcomes in sample space S.

    P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
    P(A ∩ B) = P(A) × P(B|A) = P(B) × P(A|B)
    If independent: P(A ∩ B) = P(A) × P(B)

    Conditional probability: P(A|B) = P(A ∩ B)/P(B).

    Bayes' theorem (the exam's most-asked probability formula):

    P(A|B) = P(B|A) × P(A) / P(B)
    P(B) = P(B|A)P(A) + P(B|¬A)P(¬A) — total probability

    Example: 1% of a population has a disease. A test has 99% sensitivity (true positive) and 95% specificity (true negative). If someone tests positive, what is the probability they have the disease?

    P(D) = 0.01, P(+|D) = 0.99, P(+|¬D) = 0.05
    P(+) = 0.99×0.01 + 0.05×0.99 = 0.0099 + 0.0495 = 0.0594
    P(D|+) = 0.0099/0.0594 ≈ 16.67%

    Expected value: E(X) = Σ xi P(xi). Variance: Var(X) = E(X²) − [E(X)]².

    Bayes' theorem questions always look surprising — a 99%-accurate test can still give a low probability of disease if the disease is rare. The base rate dominates when prevalence is low.

    6. Graph theory

    A graph G = (V, E) is a set of vertices and edges. Undirected: edges are unordered pairs. Directed (digraph): edges are ordered pairs.

    Key definitions:

    • Degree: number of edges incident to a vertex. Sum of degrees = 2|E| (handshaking lemma).
    • Path: sequence of vertices connected by edges with no repeated edges.
    • Cycle: a path that starts and ends at the same vertex.
    • Connected: there is a path between every pair of vertices.
    • Tree: connected acyclic graph; |E| = |V| − 1.

    Special graphs:

    GraphVerticesEdgesProperty
    Complete Knnn(n−1)/2Every pair connected
    Bipartite Km,nm+nm×nTwo groups, edges only between groups
    Cycle CnnnSingle cycle
    Treenn−1Connected, acyclic

    Euler vs Hamilton:

    EulerHamilton
    VisitsEvery edge exactly onceEvery vertex exactly once
    Circuit exists iffAll vertices have even degreeNo simple test (NP-complete)
    Path exists iffExactly 0 or 2 odd-degree verticesNo simple test

    Graph colouring: assign colours to vertices so no two adjacent vertices share a colour. The chromatic number χ(G) is the minimum colours needed. For a complete graph: χ(Kn) = n. For a tree: χ = 2. For a cycle: χ = 2 (even length) or 3 (odd length).

    Euler circuits are polynomial-time testable (check degrees), while Hamiltonian circuits are NP-complete. This distinction itself is an exam-worthy fact.

    7. Boolean algebra

    Boolean algebra uses the same operations as propositional logic but with hardware notation: AND (·), OR (+), NOT (overbar or ′).

    Key laws:

    Idempotent: A + A = A, A · A = A
    Complement: A + A′ = 1, A · A′ = 0
    Absorption: A + AB = A, A(A+B) = A
    De Morgan: (AB)′ = A′+B′, (A+B)′ = A′B′
    Consensus: AB + A′C + BC = AB + A′C

    Canonical forms: SOP (Sum of Products / minterms) and POS (Product of Sums / maxterms). Every Boolean function has a unique SOP and POS.

    Karnaugh Map (K-map) — the standard exam simplification method for up to 4 variables:

    1. Draw the grid with Gray-code ordering on axes

      2-var: 2×2, 3-var: 2×4, 4-var: 4×4.

    2. Fill in the 1s from the minterms

      Place a 1 in each cell corresponding to a minterm in the function.

    3. Group adjacent 1s into powers of 2

      Groups can be 1, 2, 4, 8 or 16 cells. The map wraps around.

    4. Read off the simplified expression

      Each group becomes one product term; variables that don't change within the group stay.

    Example: simplify F(A,B,C) = Σm(0,1,2,5,7)

    Group 1 (m0,m1): A′B′ (top-left pair)
    Group 2 (m0,m2): A′C′ (wrap-around top row ends)
    Group 3 (m5,m7): AC (bottom row, BC=01,11 → B changes, so AC stays)
    F = A′B′ + A′C′ + AC
    K-maps wrap around — the leftmost column is adjacent to the rightmost. Missing this is the most common exam mistake.

    8. Automata

    A DFA (Deterministic Finite Automaton) is a 5-tuple (Q, Σ, δ, q₀, F): states, alphabet, transition function, start state, accept states.

    A NFA (Non-deterministic FA) allows multiple transitions on the same input and ε-transitions (free moves). Every NFA can be converted to an equivalent DFA (subset construction), but the DFA may have up to 2n states.

    Example: DFA accepting strings over {0,1} that end in "01".

    Language hierarchy (Chomsky):

    TypeLanguageRecognizerExample
    3RegularDFA/NFAa*b, (01)*
    2Context-freePDAaⁿbⁿ
    1Context-sensitiveLBAaⁿbⁿcⁿ
    0Recursively enumerableTuring machineHalting problem complement

    Regular expressions and DFAs are equivalent in power. A regex uses: concatenation (ab), union (a|b), Kleene star (a*). The pumping lemma proves a language is NOT regular: for regular L, ∃p such that any w ∈ L with |w| ≥ p can be split w = xyz with |xy| ≤ p, |y| ≥ 1, and xyiz ∈ L for all i ≥ 0.

    DFAs have exactly one transition per (state, symbol) pair — no ambiguity. NFAs allow multiple or zero transitions, and they accept if any path reaches an accept state. The subset construction systematically tracks all possible NFA states as single DFA states.

    9. Number theory

    Divisibility: a | b means b = ka for some integer k. GCD (greatest common divisor) via Euclid's algorithm:

    gcd(a, b) = gcd(b, a mod b), base: gcd(a, 0) = a

    Example: gcd(252, 105)

    252 = 2 × 105 + 42
    105 = 2 × 42 + 21
    42 = 2 × 21 + 0
    gcd(252, 105) = 21

    Modular arithmetic: a ≡ b (mod n) means n | (a−b).

    (a + b) mod n = [(a mod n) + (b mod n)] mod n
    (a × b) mod n = [(a mod n) × (b mod n)] mod n

    Fermat's Little Theorem: if p is prime and gcd(a,p) = 1, then ap−1 ≡ 1 (mod p).

    Euler's totient φ(n) = count of integers 1..n coprime to n. For prime p: φ(p) = p−1. For pk: φ(pk) = pk − pk−1. This is used in RSA encryption.

    Euclid's algorithm runs in O(log(min(a,b))) steps — extremely fast. The Extended Euclidean Algorithm additionally finds x, y such that ax + by = gcd(a,b), which is essential for computing modular inverses in cryptography.

    10. Recurrence relations

    A recurrence relation defines a sequence in terms of previous terms. The exam typically asks you to solve a linear recurrence.

    Common recurrences and their solutions:

    RecurrenceSolutionWhere it appears
    T(n) = T(n−1) + cO(n)Linear scan
    T(n) = T(n−1) + nO(n²)Selection sort
    T(n) = 2T(n/2) + nO(n log n)Merge sort
    T(n) = 2T(n/2) + cO(n)Binary tree traversal
    T(n) = T(n/2) + cO(log n)Binary search

    Solving linear recurrences (e.g. an = c₁an−1 + c₂an−2): find the characteristic equation r² = c₁r + c₂ and solve for r.

    Example: solve an = an−1 + an−2 with a₀ = 0, a₁ = 1 (Fibonacci).

    Characteristic: r² − r − 1 = 0
    r = (1 ± √5)/2 → r₁ = φ ≈ 1.618, r₂ = ψ ≈ −0.618
    General: an = Aφⁿ + Bψⁿ
    Using a₀=0, a₁=1: A = 1/√5, B = −1/√5
    an = (φⁿ − ψⁿ)/√5

    Master theorem for divide-and-conquer recurrences T(n) = aT(n/b) + f(n):

    Let c = logb(a)
    Case 1: f(n) = O(nc−ε) → T(n) = Θ(nc)
    Case 2: f(n) = Θ(nc) → T(n) = Θ(nc log n)
    Case 3: f(n) = Ω(nc+ε) → T(n) = Θ(f(n))
    The Master theorem handles most exam recurrences. For Fibonacci-type recurrences, the characteristic equation method is needed. For non-homogeneous recurrences (with a constant term), find the particular solution and add it to the homogeneous solution.

    Solved past questions

    10 questions
    S1 Show that p → (q → p) is a tautology using a truth table. standard repeat
    pqq → pp → (q → p)
    TTTT
    TFTT
    FTFT
    FFTT

    All entries in the final column are T → tautology.

    Row 3 explanation: p=F makes p → (anything) true, regardless of q → p.

    S2 In a class of 60 students, 30 study Math, 25 study Physics, and 10 study both. How many study neither? standard repeat
    |M ∪ P| = |M| + |P| − |M ∩ P| = 30 + 25 − 10 = 45
    Neither = Total − |M ∪ P| = 60 − 45 = 15 students
    S3 How many ways can 5 people be seated in a row of 3 chairs? standard repeat

    Order matters (seating positions are distinct) → permutation.

    P(5,3) = 5!/(5−3)! = 5!/2! = 120/2 = 60

    Alternatively: 5 choices × 4 choices × 3 choices = 60.

    S4 A committee of 3 is to be formed from 5 men and 4 women. How many committees have at least one woman? standard repeat

    Use the complement: "at least one woman" = total − "no women".

    Total committees = C(9,3) = 84
    All-men committees = C(5,3) = 10
    At least one woman = 84 − 10 = 74
    S5 Two dice are rolled. What is the probability the sum is 7? standard repeat
    Total outcomes = 6 × 6 = 36
    Favourable: (1,6),(2,5),(3,4),(4,3),(5,2),(6,1) = 6
    P(sum=7) = 6/36 = 1/6
    S6 Find gcd(48, 18) using the Euclidean algorithm, and express it as a linear combination of 48 and 18. standard repeat
    1. Euclidean algorithm
      48 = 2 × 18 + 12
      18 = 1 × 12 + 6
      12 = 2 × 6 + 0
      gcd(48, 18) = 6
    2. Back-substitute (Extended Euclidean)
      6 = 18 − 1 × 12
      12 = 48 − 2 × 18
      6 = 18 − 1 × (48 − 2×18) = 3×18 − 1×48
      6 = 3(18) + (−1)(48)
      Verify: 3×18 − 48 = 54 − 48 = 6 ✓
    S7 A graph has 5 vertices with degrees 2, 3, 3, 4, 4. Does it have an Euler circuit? An Euler path? standard repeat
    Sum of degrees = 2+3+3+4+4 = 16 → |E| = 8
    Odd-degree vertices: 3, 3 → count = 2

    Euler circuit: requires all vertices to have even degree. Two vertices (degree 3) are odd → No Euler circuit.

    Euler path: requires exactly 0 or 2 odd-degree vertices. There are exactly 2 → Yes, an Euler path exists (start at one odd-degree vertex, end at the other).

    S8 Simplify F(A,B,C,D) = Σm(0,1,2,5,8,9,10) using a K-map. standard repeat
    1. Place 1s in the 4-variable K-map (AB vs CD)

      Minterms: 0(0000), 1(0001), 2(0010), 5(0101), 8(1000), 9(1001), 10(1010).

    2. Group the 1s

      Group 1 (m0,m1,m8,m9): {0000,0001,1000,1001} → B′D′ changes, A and C vary freely? Let's check: B=0 for all, C=0 for all. So: B′C′ (4-cell group).

      Group 2 (m0,m2,m8,m10): {0000,0010,1000,1010} → D=0 for all, B=0 for all → B′D′ (4-cell group).

      Group 3 (m5): {0101} → only groups with m1 already covered. m5 = A′B′CD. Can pair with m1 (0001): differ only in C → A′B′D.

    3. Combine
      F = B′C′ + B′D′ + A′B′D
      Can also be written: F = B′(C′ + D′ + A′D) = B′(C′ + D′ + A′D)
    S9 Design a DFA over {a, b} that accepts strings with an even number of a's. standard repeat

    States: q₀ (even a's, start/accept), q₁ (odd a's).

    StateInput aInput bAccept?
    → q₀*q₁q₀Yes
    q₁q₀q₁No

    The DFA has 2 states. It toggles between even and odd on each 'a'; 'b' doesn't change state. The empty string has 0 a's (even), so q₀ is an accept state.

    Regex equivalent: (b* a b* a b*)* = (b | ab*a)*

    S10 Solve the recurrence T(n) = 2T(n/2) + n, T(1) = 1 using the Master theorem. standard repeat
    1. Identify parameters
      a = 2, b = 2, f(n) = n
      c = logb(a) = log₂(2) = 1
    2. Compare f(n) with nc
      f(n) = n = Θ(n¹) = Θ(nc)
    3. Apply Case 2
      T(n) = Θ(nc log n) = Θ(n log n)

      This is the merge-sort recurrence — confirmed O(n log n).

    P1 Prove using a truth table that ¬(p ∧ q) ≡ ¬p ∨ ¬q (De Morgan's law). practice
    pqp∧q¬(p∧q)¬p¬q¬p∨¬q
    TTTFFFF
    TFFTFTT
    FTFTTFT
    FFFTTTT

    Columns ¬(p∧q) and ¬p∨¬q match in every row → equivalent.

    P2 Prove by induction: 1² + 2² + … + n² = n(n+1)(2n+1)/6. practice
    1. Base case: n = 1
      LHS = 1² = 1
      RHS = 1(2)(3)/6 = 1 ✓
    2. Inductive hypothesis

      Assume 1² + 2² + … + k² = k(k+1)(2k+1)/6 for some k ≥ 1.

    3. Prove for k+1
      LHS = k(k+1)(2k+1)/6 + (k+1)²
      = (k+1)[k(2k+1)/6 + (k+1)]
      = (k+1)[k(2k+1) + 6(k+1)] / 6
      = (k+1)(2k² + k + 6k + 6) / 6
      = (k+1)(2k² + 7k + 6) / 6
      = (k+1)(k+2)(2k+3) / 6
      This is the formula with n = k+1: (k+1)(k+2)(2(k+1)+1)/6 ✓
    P3 How many 4-letter words (with repetition) can be formed from the English alphabet? How many have no repeated letters? practice
    With repetition: 26⁴ = 456,976
    Without repetition: P(26,4) = 26×25×24×23 = 358,800
    P4 A bag has 5 red and 3 blue balls. Two balls are drawn without replacement. Find P(both red) and P(one of each colour). practice
    P(both red) = C(5,2)/C(8,2) = 10/28 = 5/14
    P(one each) = C(5,1)×C(3,1)/C(8,2) = 15/28 = 15/28
    Or sequentially: P(RB or BR) = (5/8)(3/7) + (3/8)(5/7) = 30/56 = 15/28 ✓
    P5 Is the graph K₃,₃ planar? How many edges does it have? Can it have an Euler circuit? practice
    |E| = 3 × 3 = 9 edges

    Planarity: For a planar bipartite graph, |E| ≤ 2|V| − 4. Here: 9 ≤ 2(6) − 4 = 8 → 9 > 8 → NOT planar. (K₃,₃ is one of Kuratowski's two non-planar graphs.)

    Euler circuit: All vertices have degree 3 (odd) → No Euler circuit. There are 6 odd-degree vertices (need exactly 0 for a circuit), so there's no Euler path either (need exactly 0 or 2 odd vertices).

    P6 Simplify using Boolean algebra: F = AB + A(B + C) + B(B + C). practice
    F = AB + AB + AC + BB + BC
    = AB + AC + B + BC   [BB = B, AB + AB = AB]
    = AB + AC + B   [B + BC = B by absorption]
    = B + AC   [AB + B = B by absorption]
    F = B + AC
    P7 Convert the NFA with ε-transition to a DFA: states {q0,q1,q2}, Σ={a,b}, q0→ε→q1, q0→a→q0, q1→b→q2, q2 is accept. practice
    1. ε-closure of start state
      ε-closure(q0) = {q0, q1}
    2. Subset construction
      DFA stateNFA statesab
      A (start){q0,q1}{q0,q1} = A{q2} = B
      B (accept){q2}∅ = C∅ = C
      C (dead)∅∅ = C∅ = C
    3. Result

      DFA has 3 states: A (start), B (accept), C (dead/trap). Accepts strings of the form a*b — any number of a's followed by exactly one b.

    P8 Find 7⁵⁰ mod 11 using Fermat's Little Theorem. practice
    1. Apply Fermat's Little Theorem
      11 is prime, gcd(7,11) = 1
      7¹⁰ ≡ 1 (mod 11)   [ap−1 ≡ 1]
    2. Reduce the exponent
      50 = 5 × 10
      7⁵⁰ = (7¹⁰)⁵ ≡ 1⁵ = 1 (mod 11)
    P9 A relation R on {1,2,3} is {(1,1),(1,2),(2,1),(2,2),(3,3)}. Is it an equivalence relation? If so, what are the equivalence classes? practice

    Check the three properties:

    • Reflexive: (1,1), (2,2), (3,3) ∈ R ✓
    • Symmetric: (1,2) ∈ R and (2,1) ∈ R ✓ (all pairs checked)
    • Transitive: (1,2) and (2,1) → (1,1) ∈ R ✓; (2,1) and (1,2) → (2,2) ∈ R ✓

    Yes, it is an equivalence relation.

    Equivalence classes: [1] = [2] = {1, 2}, [3] = {3}. The partition is {{1,2}, {3}}.

    P10 Solve an = 5an−1 − 6an−2 with a₀ = 1, a₁ = 4 using the characteristic equation. practice
    1. Characteristic equation
      r² − 5r + 6 = 0
      (r − 2)(r − 3) = 0 → r₁ = 2, r₂ = 3
    2. General solution
      an = A·2ⁿ + B·3ⁿ
    3. Solve for A, B using initial conditions
      a₀ = 1: A + B = 1
      a₁ = 4: 2A + 3B = 4
      From (1): A = 1 − B. Sub: 2(1−B) + 3B = 4 → B = 2, A = −1
      an = −2ⁿ + 2·3ⁿ
      Verify: a₂ = −4 + 18 = 14. Check: 5(4) − 6(1) = 14 ✓
