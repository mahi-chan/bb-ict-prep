    C Programming

    The exam tests C through output prediction, pointer tracing and short programs. Every question rewards knowing exactly what C does at each step — ambiguity means the examiner will exploit it.

    1. Program structure and compilation

    Every C program is a collection of functions, one of which must be main. The compiler never sees comments or macros — the preprocessor strips them before compilation begins. Understanding the pipeline explains most "why does this error happen?" questions.

    hello.c — the minimal complete program 
    #include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
    Hello, world!

    The file passes through four stages before it becomes an executable:

    TokensKeywords (32 in C89, 37 in C99), identifiers, constants, string literals, operators, punctuators.
    Header files<stdio.h> I/O · <stdlib.h> malloc/atoi · <string.h> string ops · <math.h> math · <ctype.h> char tests.
    Escape sequences\n newline · \t tab · \0 null · \\ backslash · \" double quote · \a bell.

    2. Data types, sizeof and qualifiers

    C has four basic type families: char (1 byte), int (typically 4 bytes), float (4 bytes) and double (8 bytes). The sizeof operator returns the size in bytes — it is evaluated at compile time, not runtime, and is the most frequently tested operator in exam output questions.

    sizeof demonstration 
    #include <stdio.h>

int main(void) {
    printf("char:   %zu\n", sizeof(char));
    printf("short:  %zu\n", sizeof(short));
    printf("int:    %zu\n", sizeof(int));
    printf("long:   %zu\n", sizeof(long));
    printf("float:  %zu\n", sizeof(float));
    printf("double: %zu\n", sizeof(double));
    printf("int*:   %zu\n", sizeof(int *));
    return 0;
}
    char: 1 short: 2 int: 4 long: 4 (8 on 64-bit Linux) float: 4 double: 8 int*: 4 (8 on 64-bit)
    Type Size (typical) Range (signed) Format
    char1−128 to 127%c, %d
    short2−32,768 to 32,767%hd
    int4−2³¹ to 2³¹−1%d
    long4 or 8−2³¹ to 2³¹−1 (or 2⁶³)%ld
    long long8−2⁶³ to 2⁶³−1%lld
    float4≈ ±3.4 × 10³⁸ (7 digits)%f
    double8≈ ±1.7 × 10³⁰⁸ (15 digits)%lf
    unsignedDrops the sign bit. unsigned char: 0–255. unsigned int: 0 to 2³²−1 = 4,294,967,295.
    typedeftypedef unsigned long ulong; creates an alias — no new type, just readability.
    enumenum color { RED, GREEN=5, BLUE }; → RED=0, GREEN=5, BLUE=6. Each name is an int constant.
    Integer promotion trap

    In char c = 200; printf("%d", c); the output is −56 on most systems. char is signed by default; 200 overflows to −56 in 2's complement (200 − 256). Use unsigned char to store values above 127.

    3. Operators and precedence

    C has 45 operators grouped into 15 precedence levels. The exam doesn't ask you to memorise the table — it gives you an expression and asks for the output. Knowing four rules handles almost every question: postfix binds tightest, unary beats binary, multiply before add, and assignment is right-to-left.

    Pre- vs post-increment — the classic trap 
    #include <stdio.h>

int main(void) {
    int a = 5;
    int b = a++;   /* b gets 5 (old value), then a becomes 6 */
    int c = ++a;   /* a becomes 7 first, then c gets 7       */
    printf("a=%d b=%d c=%d\n", a, b, c);
    return 0;
}
    a=7 b=5 c=7
    Operators most likely to appear in exam expressions
    Precedence Operators Associativity
    1 (highest)() [] -> .Left
    2++ -- ! ~ (type) * & sizeof (unary)Right
    3–4* / % then + -Left
    5–6<< >> then < <= > >=Left
    7–8== != then &Left
    9–11^ then | then &&Left
    12||Left
    13?: (ternary)Right
    14= += -= *= /= %= &= ^= |= <<= >>=Right
    15 (lowest), (comma)Left

    Bitwise operators

    Bitwise operations on 12 (1100) and 10 (1010) 
    #include <stdio.h>

int main(void) {
    int a = 12, b = 10;
    printf("a & b  = %d\n", a & b);   /* 1000 = 8  */
    printf("a | b  = %d\n", a | b);   /* 1110 = 14 */
    printf("a ^ b  = %d\n", a ^ b);   /* 0110 = 6  */
    printf("~a     = %d\n", ~a);      /* ...0011 = -13 (2's comp) */
    printf("a << 2 = %d\n", a << 2);  /* 110000 = 48 (×4) */
    printf("a >> 1 = %d\n", a >> 1);  /* 0110 = 6 (÷2)   */
    return 0;
}
    a & b = 8 a | b = 14 a ^ b = 6 ~a = -13 a << 2 = 48 a >> 1 = 6
    Short-circuit evaluation. In a && b, if a is 0 then b is never evaluated. In a || b, if a is non-zero then b is skipped. This is tested with side effects: int x = 0; if (x && ++x) {} printf("%d", x); prints 0 because ++x never runs.

    4. Control flow and loop tracing

    The exam gives you a loop (or nested loops) and asks "what is the output?" The only reliable method is to trace — walk the variables through each iteration. Below, one set of nested loops is traced completely so the pattern is clear.

    Pattern printing — a standard exam question 
    #include <stdio.h>

int main(void) {
    for (int i = 1; i <= 4; i++) {
        for (int j = 1; j <= i; j++)
            printf("*");
        printf("\n");
    }
    return 0;
}
    * ** *** ****
    Trace — i and j at each iteration
    ij runsStars printed
    11*
    21, 2**
    31, 2, 3***
    41, 2, 3, 4****

    break, continue and switch

    switch with fallthrough — the other classic trap 
    #include <stdio.h>

int main(void) {
    int x = 2;
    switch (x) {
        case 1: printf("one ");
        case 2: printf("two ");
        case 3: printf("three ");
                break;
        default: printf("other");
    }
    return 0;
}
    two three
    Fallthrough is the default. Without break, execution falls through every subsequent case. The exam exploits this regularly — especially by placing cases without break before a break two cases later. The output is always longer than expected.
    do-whileBody executes at least once. do { ... } while (condition); — the semicolon after the closing parenthesis is required.
    gotoUnconditional jump. Rarely appears in exams except as "what does goto do?" answer: transfers control to a labelled statement within the same function.
    Comma in forfor (i=0, j=10; i<j; i++, j--) — the comma operator evaluates left to right and returns the right value. Used to update two variables in a for-loop.

    5. Functions, recursion and storage classes

    C passes arguments by value — the function gets a copy. To modify the caller's variable, you pass a pointer (call by reference, simulated). This distinction is the single most tested function concept.

    Call by value vs call by reference 
    #include <stdio.h>

void byValue(int x)    { x = 99; }
void byRef(int *p)     { *p = 99; }

int main(void) {
    int a = 10, b = 10;
    byValue(a);
    byRef(&b);
    printf("a=%d b=%d\n", a, b);
    return 0;
}
    a=10 b=99
    byValuex is a copy of a. Changing x does not affect a.
    byRefp holds the address of b. *p = 99 writes directly to b's memory.

    Recursion

    Factorial — the standard recursion example 
    int factorial(int n) {
    if (n <= 1) return 1;       /* base case */
    return n * factorial(n - 1); /* recursive case */
}
/* factorial(5) = 5 × 4 × 3 × 2 × 1 = 120 */

    Storage classes

    Class Scope Lifetime Default init Where stored
    autoBlockBlockGarbageStack
    registerBlockBlockGarbageCPU register (hint)
    static (local)BlockProgram0Data segment
    static (global)FileProgram0Data segment
    externGlobalProgram0Data segment
    static local — the exam's favourite storage-class trick 
    #include <stdio.h>

void count(void) {
    static int n = 0;  /* initialised only once */
    n++;
    printf("%d ", n);
}

int main(void) {
    count(); count(); count();
    return 0;
}
    1 2 3
    Why static prints 1 2 3, not 1 1 1. A static local variable keeps its value between calls — the = 0 initialisation runs only on the first call. Without static, n would be re-created on the stack each call and always start at 0.

    6. Arrays

    An array is a contiguous block of same-type elements. The name of an array decays to a pointer to its first element in most contexts — this is the array–pointer duality that makes C arrays behave like pointers in function calls.

    1D array — declaration, initialisation, access 
    #include <stdio.h>

int main(void) {
    int a[5] = {10, 20, 30, 40, 50};
    printf("a[0]=%d  a[4]=%d\n", a[0], a[4]);
    printf("*(a+2) = %d\n", *(a + 2));  /* pointer arithmetic */
    printf("sizeof(a) = %zu\n", sizeof(a));     /* 20 bytes (5×4) */
    printf("elements  = %zu\n", sizeof(a)/sizeof(a[0])); /* 5 */
    return 0;
}
    a[0]=10 a[4]=50 *(a+2) = 30 sizeof(a) = 20 elements = 5
    Equivalencea[i] ≡ *(a + i) ≡ *(i + a) ≡ i[a]. Yes, 2[a] is legal C and equals a[2].
    No bounds checkC does not check array bounds. Accessing a[5] in a 5-element array reads whatever happens to be in memory — undefined behaviour.

    2D arrays

    2D array — row-major layout 
    int m[2][3] = { {1,2,3}, {4,5,6} };
/* Memory layout (row-major): 1 2 3 4 5 6 */
/* m[1][2] = *(*(m+1)+2) = 6             */
    Address of m[i][j]Base + (i × cols + j) × sizeof(element)
    Passing to functionvoid f(int a[][3], int rows) — the first dimension can be omitted but subsequent dimensions are required so the compiler knows the row stride.

    7. Strings and string.h

    C has no string type. A "string" is a char array terminated by '\0' (the null character, ASCII 0). Every string function relies on this sentinel — if it is missing, the function reads past the array and the behaviour is undefined.

    String declaration — three ways, one trap 
    char s1[] = "Hello";         /* array of 6 chars: H e l l o \0 */
char s2[] = {'H','i','\0'}; /* same idea, manual              */
char *s3  = "World";        /* pointer to string literal       */

s1[0] = 'J';  /* OK — s1 is a mutable array */
/* s3[0] = 'X'; — UNDEFINED: literals are read-only */
    Essential string.h functions
    FunctionDoesReturns
    strlen(s)Counts chars before '\0'Length (size_t)
    strcpy(d, s)Copies s into d (including '\0')d
    strcat(d, s)Appends s to end of dd
    strcmp(a, b)Lexicographic compare<0, 0, or >0
    strstr(h, n)Find substring n in hPointer or NULL
    strtok(s, d)Split s by delimiters dNext token or NULL
    Manual strlen — what the exam may ask you to write 
    int my_strlen(const char *s) {
    int len = 0;
    while (s[len] != '\0')
        len++;
    return len;
}
    strcmp returns 0 for equal. A common mistake: if (strcmp(a, b)) means "if they are different", because 0 is false in C. To test equality, write if (strcmp(a, b) == 0).

    8. Pointers and pointer arithmetic

    A pointer is a variable that stores a memory address. The two fundamental operations are & (address-of: gives the address of a variable) and * (dereference: gives the value at the address). Every pointer question on the exam reduces to tracking which address each pointer holds and what value lives there.

    Pointer basics — trace every address 
    #include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;      /* p points to x     */
    int **q = &p;     /* q points to p     */

    printf("x  = %d\n", x);       /* 42   */
    printf("*p = %d\n", *p);      /* 42   */
    printf("**q = %d\n", **q);    /* 42   */

    *p = 100;
    printf("x  = %d\n", x);       /* 100  */
    return 0;
}
    x = 42 *p = 42 **q = 42 x = 100

    Pointer arithmetic

    Pointer arithmetic steps by the pointed-to type's size 
    int a[] = {10, 20, 30, 40, 50};
int *p = a;       /* p points to a[0] */
printf("%d\n", *(p + 3));  /* 40 — jumps 3×sizeof(int) = 12 bytes */
p++;
printf("%d\n", *p);  /* 20 — p now points to a[1] */
    NULL pointerint *p = NULL; — convention for "points to nothing." Dereferencing NULL is undefined (usually a crash).
    void pointervoid *p can hold any address but cannot be dereferenced directly — must cast first: *(int *)p.
    Dangling pointerPoints to memory that has been freed or is out of scope. Reading it is undefined behaviour.
    Wild pointerUninitialized pointer — holds whatever garbage was in memory. Always initialise to NULL or a valid address.

    const with pointers

    const int *pPointer to const int. Can change p, cannot change *p. "Read the data, don't modify it."
    int *const pConst pointer to int. Cannot change p, can change *p. "Stay at this address."
    const int *const pBoth locked. Cannot change either the pointer or the value.

    9. Dynamic memory allocation

    Stack memory is automatic but limited in size and lifetime. The heap gives you memory that persists until you explicitly free it — at the cost of managing it yourself. Four functions in <stdlib.h> control heap memory.

    FunctionWhat it doesInit?
    malloc(n)Allocates n bytesNo (garbage)
    calloc(count, size)Allocates count × size bytesYes (all zeros)
    realloc(ptr, n)Resizes existing block to n bytesOld data kept
    free(ptr)Returns the block to the heap—
    Dynamic array — allocate, use, free 
    #include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 5;
    int *arr = (int *)malloc(n * sizeof(int));
    if (arr == NULL) { printf("Out of memory\n"); return 1; }

    for (int i = 0; i < n; i++)
        arr[i] = (i + 1) * 10;

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    free(arr);
    arr = NULL;   /* prevent dangling pointer */
    return 0;
}
    10 20 30 40 50
    Memory leak

    If you malloc and never free, the memory stays allocated until the program exits. In long-running programs (servers, daemons) this grows without bound. Rule: every malloc needs exactly one matching free. Double-free is equally dangerous — it corrupts the heap manager.

    Dynamic 2D array

    Allocating a 3×4 matrix on the heap 
    int rows = 3, cols = 4;
int **mat = (int **)malloc(rows * sizeof(int *));
for (int i = 0; i < rows; i++)
    mat[i] = (int *)malloc(cols * sizeof(int));

mat[1][2] = 99;  /* works like a normal 2D array */

/* free in reverse order */
for (int i = 0; i < rows; i++)
    free(mat[i]);
free(mat);

    10. Structures and unions

    A struct groups related data under one name. Each member occupies its own memory. A union overlays all members on the same memory — its size equals the largest member. The exam asks you to compare them and to predict sizeof.

    struct — define, declare, access 
    #include <stdio.h>

struct Student {
    int id;
    char name[20];
    float gpa;
};

int main(void) {
    struct Student s = {101, "Rahim", 3.85};
    printf("ID: %d, Name: %s, GPA: %.2f\n", s.id, s.name, s.gpa);

    struct Student *p = &s;
    printf("Via pointer: %s\n", p->name);  /* arrow operator */
    return 0;
}
    ID: 101, Name: Rahim, GPA: 3.85 Via pointer: Rahim
    struct vs union
    Featurestructunion
    MemorySum of all members (+ padding)Size of largest member
    AccessAll members simultaneouslyOnly one member at a time
    Use caseGroup related data (student record)Save space when only one variant is active (tagged union)
    sizeof struct vs union — the exam question 
    struct S { int a; char b; double c; };
union  U { int a; char b; double c; };

printf("struct: %zu\n", sizeof(struct S));  /* 16 (with padding) */
printf("union:  %zu\n", sizeof(union U));   /* 8  (size of double) */
    Padding and alignment. Most compilers align members to their natural boundary: a 4-byte int starts at an address divisible by 4. In struct S above, there are 3 bytes of padding after b (char) to align c (double) at an 8-byte boundary. This is why sizeof(struct S) is 16, not 13.

    Self-referential structures

    Linked list node — the foundation of dynamic data structures in C 
    struct Node {
    int data;
    struct Node *next;  /* pointer to same type */
};
/* sizeof(struct Node) = sizeof(int) + sizeof(pointer) = 4 + 4/8 */

    11. File handling

    C accesses files through a FILE * pointer returned by fopen. The mode string controls read, write, append and text vs binary. Every file opened must be closed — an unclosed file may lose buffered data.

    fopen modes
    ModeActionFile must exist?
    "r"ReadYes
    "w"Write (truncates)No (creates)
    "a"AppendNo (creates)
    "r+"Read + writeYes
    "w+"Read + write (truncates)No (creates)
    "a+"Read + appendNo (creates)
    "rb", "wb"Same as above, binary modeSame
    Write to a file and read it back 
    #include <stdio.h>

int main(void) {
    FILE *fp = fopen("data.txt", "w");
    if (fp == NULL) { perror("fopen"); return 1; }
    fprintf(fp, "Name: Karim\nScore: 85\n");
    fclose(fp);

    fp = fopen("data.txt", "r");
    char line[100];
    while (fgets(line, sizeof(line), fp) != NULL)
        printf("%s", line);
    fclose(fp);
    return 0;
}
    Name: Karim Score: 85
    fseekfseek(fp, offset, SEEK_SET/SEEK_CUR/SEEK_END) — moves the file-position indicator. Used for random access.
    ftellReturns the current position. fseek(fp, 0, SEEK_END); long size = ftell(fp); gives the file size.
    rewindrewind(fp) ≡ fseek(fp, 0, SEEK_SET) — moves back to the start.

    12. Preprocessor

    The preprocessor runs before the compiler — it does text substitution, not type checking. This is why macro bugs are so subtle: the compiler sees the expanded text, not your intent.

    The classic macro pitfall 
    #define SQUARE(x) x * x

int a = SQUARE(3 + 1);
/* Expands to: 3 + 1 * 3 + 1 = 3 + 3 + 1 = 7, NOT 16! */

#define SQUARE_SAFE(x) ((x) * (x))
int b = SQUARE_SAFE(3 + 1);
/* Expands to: ((3 + 1) * (3 + 1)) = 16 ✓ */
    Object-like#define PI 3.14159 — simple constant replacement. No parentheses needed.
    Function-like#define MAX(a,b) ((a)>(b)?(a):(b)) — always parenthesise every parameter and the whole expression.
    #include<header> searches system paths. "header" searches the current directory first.
    Conditional#ifdef DEBUG ... #endif — includes the code only if DEBUG is defined. Used for debug builds.
    #pragmaCompiler-specific directive. #pragma once prevents double inclusion (non-standard but widely supported).
    Macros have no type safety. SQUARE("hello") compiles without error — the preprocessor doesn't know types. For type-safe alternatives, use inline functions (C99).

    13. Output prediction patterns

    "What is the output?" is the most common C exam question format. Every question uses one of a small number of traps. Knowing the traps turns guessing into a systematic trace.

    Trap 1: post-increment in printf 
    int a = 5;
printf("%d %d %d", a++, a++, a++);
/* Undefined behaviour! Argument evaluation order is
   unspecified. Common outputs: "7 6 5" or "5 6 7".
   Correct exam answer: "undefined behaviour." */
    Trap 2: sizeof an array parameter 
    void f(int arr[]) {
    printf("%zu\n", sizeof(arr));  /* prints 4 or 8 (pointer size!) */
}

int main(void) {
    int a[10];
    printf("%zu\n", sizeof(a));    /* prints 40 (10 × 4 bytes) */
    f(a);
    return 0;
}
    40 4
    Trap 3: string vs character 
    char c = '5';
printf("%d\n", c);       /* 53 — the ASCII value of '5'    */
printf("%d\n", c - '0'); /* 5  — digit extraction trick    */
printf("%d\n", '0');     /* 48 — ASCII value of '0'        */
    53 5 48
    The full trap catalogue
    TrapWhat goes wrongRule to apply
    Post/pre in same exprUndefined evaluation orderNever modify and read a variable in the same statement
    sizeof array paramArray decays to pointerIn a function, sizeof(arr) = pointer size
    char arithmeticChar is an integer'A'=65, 'a'=97, '0'=48
    Switch fallthroughMissing breakExecution continues to the next case
    static localRetains valueInitialised only once, persists across calls
    String literal modifyUndefined (crash)Literals are in read-only memory
    = vs ==Assignment instead of comparisonif (x = 5) assigns 5, always true
    Dangling pointerReturns address of localLocal variables die when the function returns
    The tracing method. For any output question: (1) draw a box for each variable, (2) walk the code line by line updating the boxes, (3) write what printf emits at each call. If you trace and the answer doesn't match the options, check for undefined behaviour — the correct answer is "undefined."

    S5 Write a C program to check if a string is a palindrome. standard repeat 
    #include <stdio.h>
#include <string.h>

int isPalindrome(const char *s) {
    int left = 0, right = strlen(s) - 1;
    while (left < right) {
        if (s[left] != s[right])
            return 0;  /* not a palindrome */
        left++;
        right--;
    }
    return 1;
}

int main(void) {
    char s1[] = "madam";
    char s2[] = "hello";
    printf("%s: %s\n", s1, isPalindrome(s1) ? "YES" : "NO");
    printf("%s: %s\n", s2, isPalindrome(s2) ? "YES" : "NO");
    return 0;
}
    madam: YES hello: NO
    Trace "madam"left=0,right=4: m==m ✓ → left=1,right=3: a==a ✓ → left=2,right=2: loop ends → palindrome.
    Trace "hello"left=0,right=4: h≠o → return 0 immediately → not a palindrome.
    S6 Compare malloc, calloc, realloc and free. standard repeat
    FunctionSyntaxInitTypical use
    mallocmalloc(n * sizeof(int))GarbageGeneral heap allocation
    calloccalloc(n, sizeof(int))All zerosArrays where zero-init matters

    Key difference: malloc(n * size) and calloc(n, size) allocate the same amount of memory. The difference is that calloc zeroes out every byte and takes two arguments (count and size), while malloc takes one (total bytes) and leaves the memory uninitialised.

    Call 1count initialised to 0 (only once), incremented to 1. Prints 1.

    Call 3count retains value 2, incremented to 3. Prints 3.

    S8 Compare structure and union in C. What is the size of each? past paper 
    struct S { char a; int b; char c; };
union  U { char a; int b; char c; };
    struct Schar(1) + 3 padding + int(4) + char(1) + 3 padding = 12 bytes
    union USize of largest member = int = 4 bytes

    Why struct is 12, not 6: The compiler inserts 3 bytes of padding after the first char to align int b at a 4-byte boundary, and 3 bytes after char c to make the total struct size a multiple of 4 (for array alignment).

    S9 Write a C program to find the factorial of a number using recursion. standard repeat 
    #include <stdio.h>

long long factorial(int n) {
    if (n <= 1) return 1;
    return (long long)n * factorial(n - 1);
}

int main(void) {
    int num = 10;
    printf("%d! = %lld\n", num, factorial(num));
    return 0;
}
    10! = 3628800
    Base casen ≤ 1 → return 1. Without this, the recursion never stops (stack overflow).
    Recursive casen × factorial(n−1). Each call creates a stack frame with its own n.
    Why long long?13! = 6,227,020,800 — exceeds int range (2³¹ − 1 ≈ 2.1 billion). Using long long handles up to 20!.

    P2 Write a C function to reverse a string in place. 
    #include <stdio.h>
#include <string.h>

void reverse(char *s) {
    int left = 0, right = strlen(s) - 1;
    while (left < right) {
        char temp = s[left];
        s[left]  = s[right];
        s[right] = temp;
        left++;
        right--;
    }
}

int main(void) {
    char str[] = "Bangladesh";
    reverse(str);
    printf("%s\n", str);
    return 0;
}

    TraceSwap s[0]↔s[9]: h...B → hsedalg...B → each pair swaps inward until left ≥ right.
    ComplexityO(n/2) = O(n) time, O(1) space — no extra array needed.

    P9 Write a C program to copy the contents of one file to another. 
    #include <stdio.h>

int main(void) {
    FILE *src = fopen("input.txt", "r");
    FILE *dst = fopen("output.txt", "w");

    if (src == NULL || dst == NULL) {
        perror("Error opening file");
        return 1;
    }

    int ch;
    while ((ch = fgetc(src)) != EOF)

    fclose(src);

    return 0;
}
